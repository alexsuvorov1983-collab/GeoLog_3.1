# Этап 7: Пояснительная записка - Переключатель готовности с инвертированными цветами

## Дата
2026-01-29

## Описание изменения
Изменена логика кнопки готовности разделов на переключатель с инвертированными цветами:
- Зелёная кнопка "✓ Готово" для готовых разделов (при нажатии становится неготовым)
- Красная кнопка "✗ Не готово" для неготовых разделов (при нажатии становится готовым)

## Логика работы

### Инициализация разделов
При первом открытии пояснительной записки:
- Раздел 14 ("Сведения о контроле качества и приемке работ") → `isReady: true`
- Раздел 16 ("Список использованной литературы") → `isReady: true`
- Все остальные разделы → `isReady: false`

### Отображение кнопок

**Для готовых разделов (isReady === true):**
```
[✎ Редактировать] [↺ Автогенерация] [✓ Готово]
```
- Зелёная кнопка "✓ Готово"
- При нажатии раздел становится неготовым (красная кнопка)

**Для неготовых разделов (isReady === false):**
```
[✎ Редактировать] [↺ Автогенерация] [✗ Не готово]
```
- Красная кнопка "✗ Не готово"
- При нажатии раздел становится готовым (зелёная кнопка)

### Отображение индикаторов

**В левой панели навигации:**
- ✓ Готовый раздел: зелёная галочка
- ✗ Неготовый раздел: красный крестик

**В правой панели (заголовок раздела):**
- ✓ Готовый раздел: зелёная галочка с tooltip "Раздел готов"
- ✗ Неготовый раздел: красный крестик с tooltip "Раздел не готов"

## Реализация

### Функция переключения готовности
```typescript
const toggleSectionReady = (sectionId: string) => {
  setSections(prev => prev.map(s => 
    s.id === sectionId 
      ? { ...s, isReady: !s.isReady }
      : s
  ));
  const section = sections.find(s => s.id === sectionId);
  const newStatus = section?.isReady ? 'не готов' : 'готов';
  Journal.logEvent('info', `Раздел ${sectionId} отмечен как ${newStatus}`, 'report.section_toggle');
};
```

### Кнопка переключателя
```tsx
<button
  onClick={() => toggleSectionReady(section.id)}
  className={`px-3 py-1 text-white rounded text-sm font-semibold ${
    isReady 
      ? 'bg-green-500 hover:bg-green-600' 
      : 'bg-red-500 hover:bg-red-600'
  }`}
  title={isReady ? 'Раздел готов' : 'Раздел не готов'}
>
  {isReady ? '✓ Готово' : '✗ Не готово'}
</button>
```

## Примеры использования

### Пример 1: Первый запуск
1. Открыть окно "Пояснительная записка"
2. Раздел 14 и 16 отмечены зелёными галочками (✓)
3. Все остальные разделы отмечены красными крестиками (✗)
4. У разделов 14 и 16 — зелёные кнопки "✓ Готово"
5. У остальных разделов — красные кнопки "✗ Не готово"

### Пример 2: Отметка раздела как неготового
1. Раздел 14 отмечен как готовый (✓) с зелёной кнопкой "✓ Готово"
2. Нажать кнопку "✓ Готово"
3. Раздел отмечается красным крестиком (✗)
4. Кнопка становится красной "✗ Не готово"
5. Запись в журнал: "Раздел report-14 отмечен как не готов"

### Пример 3: Отметка раздела как готового
1. Раздел 1 отмечен как неготовый (✗) с красной кнопкой "✗ Не готово"
2. Нажать кнопку "✗ Не готово"
3. Раздел отмечается зелёной галочкой (✓)
4. Кнопка становится зелёной "✓ Готово"
5. Запись в журнал: "Раздел report-1 отмечен как готов"

### Пример 4: Многократное переключение
1. Пользователь может многократно нажимать кнопку
2. Состояние переключается каждый раз
3. Цвет кнопки меняется: зелёный ↔ красный
4. Индикаторы обновляются мгновенно
5. Запись в журнал происходит при каждом переключении

## Сохранение состояния

- Состояние готовности сохраняется в `localStorage`
- При перезагрузке страницы состояние восстанавливается
- Каждое переключение записывается в журнал событий
