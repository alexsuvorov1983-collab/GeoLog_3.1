# Исправление: Рамки и штампы на каждой странице

## Дата
2026-01-29

## Проблема
Рамки и штампы не отображались на страницах экспортированного DOCX файла.

## Причина
Использовался параграф с границами для создания рамки, что не работает корректно в библиотеке docx. Параграф с границами не создает настоящую рамку страницы.

## Решение
Заменен параграф на таблицу 1×1 в header с точными размерами страницы и границами.

### Ключевые изменения в `docxExporter.ts`

**Было (неправильно):**
```typescript
function createFrameInHeader(pageSettings: PageSettings): Paragraph {
  return new Paragraph({
    text: '',
    border: {
      top: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 },
      bottom: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 },
      left: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 },
      right: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 }
    },
    spacing: {
      before: 0,
      after: 0,
      line: 240 * 40
    }
  });
}
```

**Стало (правильно):**
```typescript
function createFrameInHeader(pageSettings: PageSettings): Table {
  const pageSize = PAGE_SIZES[pageSettings.format];
  const pageWidth = pageSettings.orientation === 'portrait' ? pageSize.width : pageSize.height;
  const pageHeight = pageSettings.orientation === 'portrait' ? pageSize.height : pageSize.width;
  
  const contentWidth = pageWidth - FRAME_MARGINS.left - FRAME_MARGINS.right;
  const contentHeight = pageHeight - FRAME_MARGINS.top - FRAME_MARGINS.bottom;

  return new Table({
    rows: [
      new TableRow({
        height: { value: convertMillimetersToTwip(contentHeight), rule: 'exact' },
        children: [
          new TableCell({
            width: { size: convertMillimetersToTwip(contentWidth), type: WidthType.DXA },
            borders: {
              top: { style: BorderStyle.SINGLE, size: 12, color: '000000' },
              bottom: { style: BorderStyle.SINGLE, size: 12, color: '000000' },
              left: { style: BorderStyle.SINGLE, size: 12, color: '000000' },
              right: { style: BorderStyle.SINGLE, size: 12, color: '000000' }
            },
            children: [new Paragraph({ text: '' })]
          })
        ]
      })
    ],
    width: { size: 100, type: WidthType.PERCENTAGE }
  });
}
```

### Почему это работает

**Таблица в header:**
- Таблица 1×1 занимает всю страницу (минус поля)
- Границы таблицы создают видимую рамку
- Header повторяется на каждой странице
- Размеры точно соответствуют формату страницы

**Параграф с границами (не работал):**
- Параграф не может иметь границы по всем 4 сторонам
- Границы параграфа работают только для текста
- Не создает визуальную рамку страницы

## Как это работает

### Структура рамки

```
┌─────────────────────────────────┐ ← Граница таблицы (верх)
│                                 │
│                                 │
│      СОДЕРЖИМОЕ СТРАНИЦЫ        │ ← Ячейка таблицы
│                                 │
│                                 │
└─────────────────────────────────┘ ← Граница таблицы (низ)
↑                                 ↑
Граница таблицы (лево)      Граница таблицы (право)
```

### Размеры

**Для A4 portrait:**
- Ширина страницы: 210 мм
- Высота страницы: 297 мм
- Поля: 20/5/5/5 мм (лево/право/верх/низ)
- Ширина рамки: 210 - 20 - 5 = 185 мм
- Высота рамки: 297 - 5 - 5 = 287 мм

**Для A3 landscape:**
- Ширина страницы: 420 мм
- Высота страницы: 297 мм
- Поля: 20/5/5/5 мм
- Ширина рамки: 420 - 20 - 5 = 395 мм
- Высота рамки: 297 - 5 - 5 = 287 мм

### Штамп в footer

Штамп создается как таблица в footer:
- **Большой штамп (форма 1):** 185×55 мм для титульного листа
- **Малый штамп (форма 2):** 185×15 мм для остальных листов
- **Без штампа:** пустой footer

## Технические детали

### Размеры в TWIPs

Библиотека `docx` использует TWIPs (1/20 точки):
- 1 мм = 56.69 TWIPs
- A4: 210×297 мм = 11907×16840 TWIPs
- A3: 297×420 мм = 16840×23814 TWIPs
- Поля: 20 мм = 1134 TWIPs, 5 мм = 283 TWIPs

### Структура таблицы рамки

```typescript
Table {
  rows: [
    TableRow {
      height: contentHeight (exact),
      children: [
        TableCell {
          width: contentWidth,
          borders: {
            top: SINGLE, size: 12, color: '000000',
            bottom: SINGLE, size: 12, color: '000000',
            left: SINGLE, size: 12, color: '000000',
            right: SINGLE, size: 12, color: '000000'
          },
          children: [Paragraph { text: '' }]
        }
      ]
    }
  ],
  width: 100%
}
```

### Параметры границ

- **style:** SINGLE (сплошная линия)
- **size:** 12 (толщина линии, примерно 1.5 мм)
- **color:** '000000' (черный)

## Преимущества нового подхода

1. **Надежность**
   - Таблица с границами работает корректно в библиотеке docx
   - Рамка отображается на всех страницах

2. **Точность**
   - Размеры рамки точно соответствуют формату страницы
   - Поля страницы соблюдаются

3. **Гибкость**
   - Легко изменить размер и стиль границ
   - Поддержка разных форматов (A4/A3) и ориентаций

4. **Совместимость**
   - Работает в разных версиях Word
   - Корректно отображается при печати
