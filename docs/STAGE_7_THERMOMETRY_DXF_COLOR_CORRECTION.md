# Этап 7: Термометрия - Корректировка оформления графика (цвета и засечки)

## Обзор

Корректировка оформления графика термометрии в DXF экспорте согласно эталону. Изменены цвета элементов и направление засечек для улучшения визуального восприятия.

## Изменения

### 1. Добавлены параметры цвета в функции line() и text()

**Файл:** `src/utils/dxfGenerator.ts` (строки 45-55)

**Было:**
```typescript
const line = (x1: number, y1: number, x2: number, y2: number) => {
  push(0, 'LINE'); push(8, LAYER); push(62, 7);
  // ...
};
const text = (x: number, y: number, h: number, s: string, ah: number, av: number) => {
  push(0, 'TEXT'); push(8, LAYER); push(7, STYLE); push(62, 7);
  // ...
};
```

**Стало:**
```typescript
const line = (x1: number, y1: number, x2: number, y2: number, color: number = 7) => {
  push(0, 'LINE'); push(8, LAYER); push(62, color);
  // ...
};
const text = (x: number, y: number, h: number, s: string, ah: number, av: number, color: number = 7) => {
  push(0, 'TEXT'); push(8, LAYER); push(7, STYLE); push(62, color);
  // ...
};
```

**Описание:**
- Добавлен параметр `color` с значением по умолчанию 7 (чёрный)
- Позволяет задавать разные цвета для разных элементов графика
- Обратная совместимость сохранена (все существующие вызовы работают без изменений)

### 2. Изменены цвета элементов графика

**Файл:** `src/utils/dxfGenerator.ts` (строки 68-81)

#### Ось глубин
```typescript
line(x0, yTop, x0, yTop - H);  // цвет 7 (чёрный) — без изменений
```

#### Засечки
```typescript
// Было: line(x0 - 2, y, x0, y);  // цвет 7, влево от оси
// Стало: line(x0, y, x0 + 2, y, 1);  // цвет 1 (красный), вправо от оси
```
- Засечки направлены вправо от оси
- Длина 2 мм
- Цвет 1 (красный)

#### Подписи глубин
```typescript
text(x0 - 3, y, 2.5, p.depth.toFixed(1), 2, 1);  // цвет 7 (чёрный) — без изменений
```

#### Значения температуры
```typescript
// Было: text(x0 + 3, vy, 2.5, fmtVal(p.t), 0, 2);  // цвет 7, позиция x0+3
// Стало: text(x0 + 4, vy, 2.5, fmtVal(p.t), 0, 2, 1);  // цвет 1, позиция x0+4
```
- Позиция: x0 + 4 мм (сразу справа от засечки)
- Цвет: 1 (красный)
- Выравнивание: 72=0, 73=2 (вертикально по центру засечки)

#### Шапка (номер скважины)

// Было: text(x0, yTop + 8, 3, row.name, 0, 0);  // цвет 7

```

#### Шапка (дата)

// Было: text(x0, yTop + 4, 3, fmtDate(row.date, dateMode), 0, 0);  // цвет 7
// Стало: text(x0, yTop + 4, 3, fmtDate(row.date, dateMode), 0, 0, 1);  // цвет 1 (красный)
```

## Цветовая схема

### COLOR_AXIS = 7 (чёрный)
- Ось глубин (вертикальная линия)
- Подписи глубин (слева от оси)

### COLOR_RED = 1 (красный)
- Шапка (номер скважины и дата)
- Засечки (горизонтальные отрезки вправо от оси)
- Значения температуры (справа от засечек)

## Визуальный результат

```
    С-1              ← красный
  15.03.2024         ← красный
    |
  0.0 |→→|  10.00    ← засечка красная, температура красная
    |    |
  2.5 |→→|   8.50    ← засечка красная, температура красная
    |    |
  5.0 |→→|  12.50    ← засечка красная, температура красная
    |    |
  7.5 |→→|  15.00    ← засечка красная, температура красная
    |    |
 10.0 |→→|  18.00    ← засечка красная, температура красная
    |
  0.0                ← подпись глубины чёрная
```

**Легенда:**
- | — ось глубин (чёрная)
- →→ — засечки (красные, направлены вправо)
- Подписи глубин слева (чёрные)
- Значения температур справа (красные)
- Шапка сверху (красная)

## Расположение элементов

```
|← 3 мм →|← 2 мм →|← 2 мм →|
         |
    Подписи   Ось    Засечки  Значения
    глубин    глубин          температур
   (x0-3)    (x0)   (x0→x0+2) (x0+4)
   чёрные    чёрная  красные   красные
```

**Горизонтальные позиции:**
- x0 - 3 мм: подписи глубин (чёрные)
- x0: вертикальная ось глубин (чёрная)
- x0 → x0 + 2 мм: засечки (красные, направлены вправо)
- x0 + 4 мм: значения температур (красные)

**Вертикальные позиции:**
- yTop + 8 мм: номер скважины (красный)
- yTop + 4 мм: дата (красная)
- yTop - depth × mmPerM: засечки, подписи глубин, значения температур

## Преимущества изменений

1. **Визуальное разделение**
   - Чёрные элементы (ось, подписи глубин) — статичная структура
   - Красные элементы (шапка, засечки, температуры) — данные
   - Легко различать структуру графика и данные

2. **Улучшенная читаемость**
   - Засечки направлены вправо к значениям температур
   - Визуальная связь между засечкой и значением
   - Нет путаницы с направлением засечек

3. **Профессиональное оформление**
   - Соответствует эталонному оформлению
   - Цветовое кодирование элементов
   - Симметричное и сбалансированное расположение

4. **Точное позиционирование**
   - Значения температур строго напротив засечек
   - Выравнивание 73=2 обеспечивает центрирование по вертикали
   - Нет смещений вроде "9.60 ниже засечки 10.0"
