# Этап 7: Пояснительная записка - Возврат к кнопке "Готово"

## Дата
2026-01-29

## Описание изменения
Возврат к предыдущей логике работы с готовностью разделов:
- По умолчанию готовы только разделы 14 и 16 (зелёная галочка ✓)
- У остальных разделов и приложений стоит красный крестик (✗)
- Во всех разделах и приложениях есть кнопка "Готово"
- При нажатии на кнопку "Готово" раздел становится готовым (зелёная галочка)
- Для готовых разделов отображается текст "✓ Готово" вместо кнопки

## Логика работы

### Инициализация разделов
При первом открытии пояснительной записки:
- Раздел 14 ("Сведения о контроле качества и приемке работ") → `isReady: true`
- Раздел 16 ("Список использованной литературы") → `isReady: true`
- Все остальные разделы → `isReady: false`

### Отображение индикаторов
**В левой панели навигации:**
- Готовый раздел: зелёная галочка (✓)
- Неготовый раздел: красный крестик (✗)

**В правой панели (заголовок раздела):**
- Готовый раздел: зелёная галочка (✓) с tooltip "Раздел готов"
- Неготовый раздел: красный крестик (✗) с tooltip "Раздел не готов"

### Кнопки управления разделом
**Для неготовых разделов:**
```
[✎ Редактировать] [↺ Автогенерация] [✓ Готово]
```
- Зелёная кнопка "✓ Готово" для отметки раздела как готового

**Для готовых разделов:**
```
[✎ Редактировать] [↺ Автогенерация] [✓ Готово]
```
- Зелёный текст "✓ Готово" (не кнопка) для индикации готовности

## Реализация

### Функция проверки готовности
```typescript
const isSectionReady = (sectionState: SectionState | undefined): boolean => {
  if (!sectionState) return false;
  return sectionState.isReady;
};
```

### Функция отметки раздела как готового
```typescript
const markSectionAsReady = (sectionId: string) => {
  setSections(prev => prev.map(s => 
    s.id === sectionId 
      ? { ...s, isReady: true }
      : s
  ));
  Journal.logEvent('info', `Раздел ${sectionId} отмечен как готовый`, 'report.section_ready');
};
```

### Кнопка "Готово"
```tsx
{!isReady ? (
  <button
    onClick={() => markSectionAsReady(section.id)}
    className="px-3 py-1 bg-green-500 hover:bg-green-600 text-white rounded text-sm font-semibold"
    title="Отметить раздел как готовый"
  >
    ✓ Готово
  </button>
) : (
  <span className="px-3 py-1 bg-green-100 text-green-700 rounded text-sm font-semibold">
    ✓ Готово
  </span>
)}
```

## Примеры использования

### Пример 1: Первый запуск
1. Открыть окно "Пояснительная записка"
2. Раздел 14 и 16 отмечены зелёными галочками (✓)
3. Все остальные разделы отмечены красными крестиками (✗)
4. У неготовых разделов есть зелёная кнопка "✓ Готово"
5. У готовых разделов отображается зелёный текст "✓ Готово"

### Пример 2: Отметка раздела как готового
1. Перейти к разделу 1 "Введение" (отмечен красным крестиком ✗)
2. Нажать кнопку "✓ Готово"
3. Раздел отмечается зелёной галочкой (✓)
4. Кнопка "✓ Готово" заменяется на текст "✓ Готово"
5. Запись в журнал: "Раздел report-1 отмечен как готовый"

### Пример 3: Редактирование готового раздела
1. Раздел 1 отмечен как готовый (✓)
2. Нажать "✎ Редактировать"
3. Внести изменения в текст
4. Нажать "✓ Сохранить"
5. Раздел остаётся готовым (✓)

### Пример 4: Сброс к автогенерации
1. Раздел отмечен как готовый (✓)
2. Нажать "↺ Автогенерация"
3. Раздел перегенерируется из данных проекта
4. Раздел остаётся готовым (✓)
