# Этап 7: Термометрия - Симметричное расположение подписей

## Дата
2026-01-29

## Описание изменения
Изменено расположение значений температуры грунта для симметричного размещения относительно подписей глубины замера.

## Проблема
Ранее подписи глубины находились на расстоянии 3 мм слева от оси (x0 - 3), а значения температуры - на расстоянии 4 мм справа от оси (x0 + 4). Это создавало визуальную асимметрию.

## Решение
Изменено расстояние для значений температуры с x0 + 4 мм на x0 + 3 мм, чтобы сделать расположение симметричным относительно вертикальной оси.

## Изменения в коде

### Файл: `src/utils/dxfGenerator.ts`

**Строка 76:**

**Было:**
```typescript
text(x0 + 4, vy, 2.5, fmtVal(p.t), 0, 1, 1);
```

**Стало:**
```typescript
text(x0 + 3, vy, 2.5, fmtVal(p.t), 0, 1, 1);
```

**Строка 80:**

**Было:**
```typescript
if (x0 + 4 + 15 > maxX) { maxX = x0 + 4 + 15; }
```

**Стало:**
```typescript
if (x0 + 3 + 15 > maxX) { maxX = x0 + 3 + 15; }
```

## Структура графика

```
|← 3 мм →|← 2 мм →|← 3 мм →|
         |
    Подписи   Ось    Засечки  Значения
    глубин    глубин  глубины  температур
   (x0-3)    (x0)   (x0-2→x0) (x0→x0+2) (x0+3)
   чёрные    чёрная  красные   красные    красные
```

**Горизонтальные позиции:**
- x0 - 3 мм: подписи глубин (чёрные)
- x0 - 2 мм → x0: левая засечка (красная, 2 мм)
- x0: вертикальная ось глубин (чёрная)
- x0 → x0 + 2 мм: правая засечка (красная, 2 мм)
- x0 + 3 мм: значения температур (красные)

## Преимущества

1. **Визуальная симметрия**
   - Подписи глубины и температуры на одинаковом расстоянии от оси (3 мм)
   - Сбалансированный внешний вид графика
   - Профессиональное оформление

2. **Улучшенное восприятие**
   - Симметричное расположение облегчает чтение данных
   - Визуальная гармония между левой и правой частями графика
   - Соответствие стандартам инженерной графики

3. **Точное соответствие**
   - Расстояние от оси до подписей глубины: 3 мм
   - Расстояние от оси до значений температуры: 3 мм
   - Полная симметрия относительно вертикальной оси
