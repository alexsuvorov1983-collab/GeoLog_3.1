# Этап 7: Модуль "Пояснительная записка"

## Обзор

Реализован полнофункциональный модуль "Пояснительная записка" (ПЗ) с плавающим окном, автогенерацией содержимого, редактированием разделов и экспортом в DOCX.

## Реализованные компоненты

### 1. Структура разделов (`src/utils/reportStructure.ts`)

Определена структура из 43 разделов:
- **Основные разделы (1-16)**: Введение, Изученность, Физико-географические условия, Методики, Геолого-геоморфологическое строение (с подразделом 5.1 Стратиграфия), Гидрогеологические условия, Свойства грунтов, Специфические грунты, Процессы, Инженерно-геологические условия, Геофизические исследования, Сейсмичность, Прогноз, Контроль качества, Заключение, Литература
- **Приложения (А-Я)**: 30 приложений с таблицами и текстом
- **Таблица регистрации изменений**

Каждый раздел имеет:
- `id` - уникальный идентификатор
- `number` - номер или обозначение
- `title` - название
- `level` - уровень вложенности (1 или 2)
- `hasTable` - наличие таблицы
- `tableHeaders` - заголовки таблицы

### 2. Автогенерация содержимого (`src/utils/reportGenerator.ts`)

Функция `generateSectionContent(sectionId)` генерирует содержимое раздела на основе данных проекта:

**Раздел 1 (Введение)**: 
- Текущая дата
- Цель и задачи изысканий
- Нормативные ссылки

**Раздел 4 (Методики)**:
- Количество скважин
- Общая глубина бурения
- Количество проб (монолиты, нарушенные, воды)
- Сессии термометрии

**Раздел 5.1 (Стратиграфия)**:
- Уникальные типы грунтов из soil_layers
- Интервалы глубин для каждого типа
- Таблица с типами, интервалами и средней мощностью

**Раздел 6 (Гидрогеологические условия)**:
- Водопроявления из water_layers
- Глубины, типы вод
- Таблица с данными

**Раздел 7 (Свойства грунтов)**:
- Общее количество проб
- Ссылка на Приложение Д

**Раздел 10 (Инженерно-геологические условия)**:
- Количество ИГЭ
- Количество водоносных горизонтов

**Раздел 15 (Заключение)**:
- Итоговые объёмы работ
- Основные выводы
- Рекомендации

**Раздел 16 (Литература)**:
- 10 основных нормативных документов (СП, ГОСТ)

**Приложения с таблицами**:
- **Г**: Каталог скважин (координаты, отметки, глубины, даты)
- **Д**: Сводная таблица свойств грунтов по ИГЭ
- **Е**: Ведомость агрессивного воздействия
- **Ж**: Засоленность грунтов
- **И**: Паспорта компрессионных испытаний
- **К**: Мёрзлые грунты
- **Л**: Химический анализ вод
- **М**: Коррозионная агрессивность
- **Н**: Деформация пучения
- **П, Т**: Трёхосное сжатие
- **Р**: Истираемость
- **С**: Сила морозного пучения
- **У**: Оценка прочности (ДальНИИС)
- **Х**: Статическое зондирование
- **Ц**: Динамическое зондирование
- **Ш**: Штамповые испытания
- **Щ**: Крыльчатка
- **Э**: Коррозионная агрессивность (удельное сопротивление)
- **Ю**: Блуждающие токи
- **Я**: Акт сдачи-приёмки
- **Таблица изменений**: Пустая таблица с 6 строками

### 3. Экспорт в DOCX (`src/utils/docxExporter.ts`)

Функция `generateDocx(projectName, sections)` создаёт документ Word:

**Структура документа**:
1. **Титульный лист** (без номера страницы):
   - Министерство строительства РФ
   - Название проекта
   - "ПОЯСНИТЕЛЬНАЯ ЗАПИСКА"
   - "к проектной документации"
   - "ИНЖЕРНО-ГЕОЛОГИЧЕСКИЕ ИЗЫСКАНИЯ"
   - Год

2. **Таблица регистрации изменений** (на отдельной странице)

3. **Оглавление** (TableOfContents):
   - Автоматическое формирование из заголовков
   - Гиперссылки
   - Примечание: "Откройте файл в Word и обновите поле оглавления (Ctrl+A, F9)"

4. **Основные разделы (1-16)**:
   - Заголовки Heading1/Heading2
   - Текст с абзацными отступами
   - Полуторный интервал
   - Таблицы с серыми заголовками

5. **Приложения (А-Я)**:
   - Каждое с новой страницы (pageBreakBefore)
   - Заголовки по центру
   - Таблицы с границами

**Оформление**:
- Формат: A4
- Поля: слева 30 мм, справа 10 мм, сверху/снизу 20 мм
- Шрифт: Times New Roman 14 (основной текст)
- Интервал: полуторный (360 twips)
- Выравнивание: по ширине
- Абзацный отступ: 1.25 см
- Таблицы: шрифт 10-12, одинарные границы, ширина 100%
- Колонтитулы: номер страницы по центру (начиная с секции 3)

**Используемые библиотеки**:
- `docx` - генерация DOCX файлов
- `file-saver` - скачивание файлов

### 4. Плавающее окно (`src/components/ReportWindow.tsx`)

**Компонент ReportWindow** - полнофункциональное плавающее окно:

**Функции окна**:
- **Перетаскивание**: за шапку окна
- **Изменение размера**: за правый нижний угол
- **Сворачивание**: кнопка "—" (до полоски шапки)
- **Разворачивание**: кнопка "□" (на весь экран)
- **Закрытие**: кнопка "×"
- **Сохранение состояния**: позиция и размер в localStorage

**Интерфейс**:
- **Левая панель** (280px, сворачиваемая):
  - Список из 43 разделов
  - Подсветка активного раздела (scrollspy)
  - Индикатор несохранённых изменений (красная точка)
  - Клик по разделу → плавная прокрутка к разделу

- **Правая панель** (прокручиваемая):
  - Заголовки разделов (H1/H2)
  - Текстовое содержимое
  - Таблицы с данными
  - Панель кнопок для каждого раздела

**Управление разделами**:
- **Редактировать**: открывает режим правки
  - Текст → textarea
  - Таблицы → input в каждой ячейке
- **Сохранить**: сохраняет изменения в localStorage
- **Отменить**: откат к последнему сохранённому состоянию
- **Автогенерация**: сброс к автоматически сгенерированному содержимому

**Экспорт**:
- Кнопка "💾 DOCX" в шапке окна
- Генерация файла `<projectName>_ПЗ.docx`
- Уведомление об успешном экспорте
- Запись в журнал

**Состояние**:
- `windowState`: позиция, размер, состояние (свёрнуто/развёрнуто)
- `sections`: массив из 43 разделов с содержимым
- `editingSection`: ID редактируемого раздела
- `editText`, `editTableRows`: временные данные редактирования
- `activeSection`: ID активного раздела (для подсветки)
- `showNavigation`: видимость левой панели

**Сохранение**:
- Состояние окна → `localStorage['geolog_report_window_state']`
- Содержимое разделов → `localStorage['geolog_report_sections']`
- Автоматическое сохранение при изменениях
