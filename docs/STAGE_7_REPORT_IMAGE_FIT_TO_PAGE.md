# Этап 7: Пояснительная записка - Изображения вписываются в лист A4

## Дата
2026-01-29

## Описание изменения
Изменено отображение загруженных изображений в приложениях пояснительной записки. Теперь изображения вписываются в лист A4, заполняя всю доступную область с учётом полей.

## Что изменилось

### Старое отображение
- Изображения центрировались на листе
- Сохраняли пропорции (object-contain)
- Могли не заполнять всю область листа

```
┌─────────────────────────────┐
│  20mm                       │
│                             │
│      ┌───────────┐          │
│      │           │          │  ← Изображение центрировано
│      │   [IMG]   │          │     не заполняет лист
│      │           │          │
│      └───────────┘          │
│                             │
│                        20mm │
└─────────────────────────────┘
```

### Новое отображение
- Изображения заполняют всю доступную область листа
- Доступная область: 170mm × 257mm (после вычета полей 20mm)
- Сохранение пропорций (object-contain)
- Фиксированная высота листа 297mm

```
┌─────────────────────────────┐
│  20mm                       │
│  ┌───────────────────────┐  │
│  │                       │  │
│  │                       │  │
│  │                       │  │  ← Изображение заполняет
│  │      [ИЗОБРАЖЕНИЕ]    │  │     всю доступную область
│  │                       │  │

│  │                       │  │
│  └───────────────────────┘  │
│                        20mm │

         170mm × 257mm
```

## Реализация

### Изменения в CSS

**Контейнер листа A4:**
```tsx
<div 
  className="bg-white shadow-lg mx-auto relative"
  style={{
    width: '210mm',
    height: '297mm',              // Фиксированная высота (было minHeight)
    padding: '20mm',
    pageBreakBefore: 'always',
    boxSizing: 'border-box'       // Padding учитывается в общей высоте
  }}
>
```

**Изображение:**
```tsx
<img 
  src={image} 
  alt={`Изображение ${idx + 1}`}
  className="w-full h-full object-contain"  // Заполняет всю область
  style={{
    display: 'block'
  }}
/>
```

### Ключевые изменения

1. **Фиксированная высота листа**
   - Было: `minHeight: '297mm'`
   - Стало: `height: '297mm'`
   - Лист теперь имеет точную высоту A4

2. **Box-sizing**
   - Добавлено: `boxSizing: 'border-box'`
   - Padding (20mm) учитывается в общей высоте
   - Доступная область для изображения: 297mm - 2×20mm = 257mm

3. **Размеры изображения**
   - Было: `max-w-full max-h-full object-contain`
   - Стало: `w-full h-full object-contain`
   - Изображение заполняет всю доступную область (170mm × 257mm)

4. **Убрано flexbox центрирование**
   - Удалены: `display: 'flex'`, `alignItems: 'center'`, `justifyContent: 'center'`
   - Изображение позиционируется в начале контейнера

5. **Добавлен relative**
   - Добавлено: `relative` к классам контейнера
   - Для корректного позиционирования кнопки удаления

## Доступная область для изображения

**Размеры листа A4:**
- Ширина: 210mm
- Высота: 297mm

**Поля:**
- Все поля: 20mm

**Доступная область:**
- Ширина: 210mm - 2×20mm = **170mm**
- Высота: 297mm - 2×20mm = **257mm**

**Соотношение сторон:**
- 170:257 ≈ 1:1.51
- Близко к соотношению A4 (1:1.414)

## Поведение изображений

### Изображения с разным соотношением сторон

**Портретная ориентация (высокие изображения):**
```
┌─────────────────┐
│                 │
│                 │
│    ┌─────┐      │
│    │     │      │  ← Изображение заполняет высоту
│    │ IMG │      │     ширина ограничена
│    │     │      │
│    └─────┘      │
│                 │
└─────────────────┘
```

**Альбомная ориентация (широкие изображения):**
```
┌─────────────────────────────┐
│                             │
│  ┌─────────────────────┐    │  ← Изображение заполняет ширину
│  │                     │    │     высота ограничена
│  │       IMG           │    │
│  └─────────────────────┘    │
│                             │
└─────────────────────────────┘
```

**Квадратные изображения:**
```
┌─────────────────┐
│                 │
│    ┌───────┐    │
│    │       │    │  ← Изображение заполняет
│    │  IMG  │    │     и ширину, и высоту
│    │       │    │     (или одну из них)
│    └───────┘    │
│                 │
└─────────────────┘
```

### Object-contain

- Изображение масштабируется, чтобы полностью поместиться в доступную область
- Пропорции сохраняются
- Пустое пространство заполняется прозрачностью (или белым фоном контейнера)

## Преимущества нового отображения

### 1. Максимальное использование пространства
- Изображения заполняют всю доступную область листа
- Нет пустого пространства вокруг изображений
- Более профессиональный вид документа

### 2. Готовность к печати
- Изображения правильно масштабируются для печати
- Не требуется дополнительная настройка размера
- Соответствует стандартам оформления приложений

### 3. Единый стиль
- Все изображения имеют одинаковый размер области
- Предсказуемое поведение для разных типов изображений
- Легко ориентироваться в документе

### 4. Сохранение пропорций
- Изображения не искажаются
- Object-contain гарантирует сохранение соотношения сторон
- Подходит для любых типов изображений
