# Этап 7: Пояснительная записка - Рамки и штампы по умолчанию

## Дата
2026-01-29

## Описание изменения

Добавлены рамки и малые штампы на каждую страницу пояснительной записки по умолчанию. Функция "Настройки листа" сохранена для возможности изменения формата, ориентации и типа штампа для каждого раздела.

## Что изменилось

### 1. Упрощение создания рамки

**Было:** Рамка создавалась через таблицу 1×1 в header
```typescript
function createFrameInHeader(pageSettings: PageSettings): Table {
  return new Table({
    rows: [new TableRow({
      children: [new TableCell({
        borders: { ... },
        ...
      })]
    })]
  });
}
```

**Стало:** Рамка создаётся через параграф с границами
```typescript
function createFrameInHeader(pageSettings: PageSettings): Paragraph {
  return new Paragraph({
    text: '',
    border: {
      top: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 },
      bottom: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 },
      left: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 },
      right: { style: BorderStyle.SINGLE, size: 12, color: '000000', space: 1 }
    },
    spacing: {
      before: 0,
      after: 0,
      line: 240 * 40 // Высота строки для заполнения страницы
    }
  });
}
```

**Преимущества:**
- Более простой и надежный подход
- Параграф с границами лучше поддерживается библиотекой docx
- Меньше вероятность ошибок при генерации

### 2. Настройки по умолчанию

Все разделы получают настройки по умолчанию:
- **Формат:** A4
- **Ориентация:** portrait (вертикальная)
- **Штамп:** small (малый штамп)

```typescript
const settings = pageSettings[section.id] || { 
  format: 'A4', 
  orientation: 'portrait', 
  stamp: 'small' 
};
```

### 3. Функция "Настройки листа" сохранена

Пользователь может изменить настройки для любого раздела:
- Кнопка "📄" в навигации окна ПЗ
- Диалог выбора формата (A4/A3)
- Диалог выбора ориентации (portrait/landscape)
- Диалог выбора типа штампа (big/small/none)

## Как это работает

### Рамка страницы

Рамка создаётся через параграф с границами в header:
- Все 4 границы: стиль SINGLE, размер 12 (толстая линия), цвет чёрный
- Параграф заполняет всю высоту страницы (line: 240 * 40)
- Header повторяется на каждой странице

### Штамп в footer

Штамп создаётся как таблица в footer:
- **Большой штамп (форма 1):** 185×55 мм для титульного листа
- **Малый штамп (форма 2):** 185×15 мм для остальных листов
- **Без штампа:** пустой footer

### Поля страницы

Поля устанавливаются согласно ГОСТ Р 21.1101:
- Левое: 20 мм (для переплёта)
- Правое: 5 мм
- Верхнее: 5 мм
- Нижнее: 5 мм

## Технические детали

### Размеры рамки

Параграф с границами:
- Размер границ: 12 (толстая линия, примерно 1.5 мм)
- Цвет: чёрный (#000000)
- Стиль: SINGLE (сплошная линия)
- Высота строки: 240 * 40 = 9600 twips (заполняет страницу)

### Размеры штампов

**Большой штамп (форма 1):**
```
┌─────────────────────────────────┐
│      Организация                │
│   Название документа            │
│        Шифр                     │
└─────────────────────────────────┘
185 мм × 55 мм
```

**Малый штамп (форма 2):**
```
┌─────────────────────────────────┐
│ Шифр  Лист X  Листов Y          │
└─────────────────────────────────┘
185 мм × 15 мм
```

### Структура секции

```typescript
{
  properties: {
    page: {
      size: { width, height, orientation },
      margin: { top: 5mm, right: 5mm, bottom: 5mm, left: 20mm }
    }
  },
  headers: {
    default: new Header({
      children: [frameParagraph]  // Рамка
    })
  },
  footers: {
    default: new Footer({
      children: [stampTable]  // Штамп
    })
  },
  children: [...]  // Содержимое раздела
}
```

4. **Совместимость**

   - Меньше проблем с отображением
