# Этап 7: Термометрия - Симметричное расположение подписей

## Обзор

Подписи температур перемещены на симметричное расстояние от центральной оси глубин, чтобы соответствовать расположению подписей глубин.

## Изменения

### Позиционирование подписей температур

**Файл:** `src/utils/dxfGenerator.ts` (строка 76)

**Было:**
```typescript
text(x0 + 10, vy, 2.5, fmtVal(p.t), 0, 2);
```

**Стало:**
```typescript
text(x0 + 3, vy, 2.5, fmtVal(p.t), 0, 2);
```

**Описание:**
- Подписи температур перемещены с x0+10 на x0+3 мм
- Теперь симметричны подписям глубин (x0-3 мм)
- Расстояние от центральной оси одинаковое: 3 мм

### Обновление расчёта экстентов

**Файл:** `src/utils/dxfGenerator.ts` (строка 80)

**Было:**
```typescript
if (x0 + 10 + 15 > maxX) { maxX = x0 + 10 + 15; }
```

**Стало:**
```typescript
if (x0 + 3 + 15 > maxX) { maxX = x0 + 3 + 15; }
```

**Описание:**
- Обновлён расчёт maxX для учёта новой позиции подписей
- maxX = x0 + 3 (позиция подписей) + 15 (запас на текст)

## Симметрия расположения

```
|← 3 мм →|← 3 мм →|
         |
    Подписи   Ось     Подписи
    глубин    глубин  температур
   (x0-3)    (x0)     (x0+3)
```

**Горизонтальные позиции:**
- x0 - 3 мм: подписи глубин (слева от оси)
- x0: вертикальная ось глубин
- x0 + 3 мм: подписи температур (справа от оси)

**Вертикальные позиции:**
- Одинаковые для глубин и температур
- vy = yTop - depth × mmPerM
- Каждая температура находится на высоте своей засечки

## Преимущества

1. **Визуальная симметрия**
   - Подписи глубин и температур на одинаковом расстоянии от оси
   - Сбалансированный внешний вид графика
   - Профессиональное оформление

2. **Улучшенная читаемость**
   - Легко сопоставить глубину и температуру
   - Нет визуального разрыва между связанными данными
   - Компактное расположение

3. **Соответствие стандартам**
   - Симметричное оформление инженерных графиков
   - Аналогично оформлению в эталонных инструментах
   - Улучшает восприятие данных

## Пример расчёта координат

**Входные данные:**
- x0 = 10 мм (позиция оси глубин)
- Глубина: 5.0 м
- Температура: 12.50 °C
- Масштаб: 1:100 (mmPerM = 10)
- yTop = 0 мм

**Расчёт:**
```
vy = 0 - 5.0 × 10 = -50.00 мм
Позиция текста глубины: (10 - 3, -50.00) = (7.00, -50.00)
Позиция текста температуры: (10 + 3, -50.00) = (13.00, -50.00)
```

**Результат:**
- Текст глубины "5.0" размещён на 3 мм левее оси глубин
- Текст температуры " 12.50" размещён на 3 мм правее оси глубин
- Оба текста на высоте -50.00 мм (соответствует глубине 5.0 м)
- Симметричное расположение относительно оси

## Раскладка графика

```
|← 3 мм →|← 3 мм →|
         |
    Подписи   Ось     Подписи
    глубин    глубин  температур
   (x0-3)    (x0)     (x0+3)
              |
         Засечки
        (x0-2 до x0)
```

**Горизонтальные позиции:**
- x0 - 3 мм: подписи глубин
- x0 - 2 мм: начало засечек
- x0: вертикальная ось глубин, конец засечек
- x0 + 3 мм: подписи температур

**Вертикальные позиции:**
- yTop - depth × mmPerM: высота для каждой глубины
- Засечки, подписи глубин и подписи температур на одной высоте
