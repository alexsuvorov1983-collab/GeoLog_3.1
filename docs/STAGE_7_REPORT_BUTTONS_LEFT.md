# Этап 7: Пояснительная записка - Перенос кнопок управления влево

## Дата
2026-01-29

## Описание изменения
Изменена структура интерфейса окна "Пояснительная записка":
1. Убраны разделительные линии между разделами
2. Кнопки управления и индикаторы готовности перенесены в левую часть от листа A4
3. Создана дополнительная панель слева для кнопок управления

## Изменения в интерфейсе

### До изменения:
```
┌─────────────────────────────────────────┐
│ ✓ НАЗВАНИЕ РАЗДЕЛА  [Редактировать] ... │ ← Заголовок с кнопками справа
│ ─────────────────────────────────────── │ ← Разделительная линия
│                                         │
│ Текст раздела...                        │
│                                         │
└─────────────────────────────────────────┘
```

### После изменения:
```
┌──────────┬──────────────────────────────┐
│ ✓        │ НАЗВАНИЕ РАЗДЕЛА             │ ← Заголовок без линии
│          │                              │
│ [Редакт] │ Текст раздела...             │ ← Кнопки слева
│ [Автог]  │                              │
│ [Готово] │                              │
└──────────┴──────────────────────────────┘
```

## Технические детали

### Структура компонентов

**Новая структура для каждого раздела:**

```tsx
<div className="mb-8 flex gap-4">
  {/* Левая панель с кнопками управления */}
  <div className="flex-shrink-0 w-48 flex flex-col gap-2 pt-4">
    {/* Индикатор готовности */}
    <div className="text-4xl text-center">✓ или ✗</div>
    
    {/* Кнопки управления */}
    <button>✎ Редактировать</button>
    <button>↺ Автогенерация</button>
    <button>✓ Готово / ✗ Не готово</button>
  </div>
  
  {/* Лист A4 */}
  <div className="bg-white shadow-lg flex-1" style={{maxWidth: '210mm'}}>
    {/* Заголовок раздела (без разделительной линии) */}
    <div className="mb-4">
      <h2>НАЗВАНИЕ РАЗДЕЛА</h2>
    </div>
    
    {/* Содержимое раздела */}
    <div>Текст или таблица...</div>
  </div>
</div>
```

### Удалённые элементы

1. **Разделительная линия между разделами**
   - Удалён класс `border-b-2 border-gray-300` из заголовка раздела
   - Удалён класс `pb-2` (padding-bottom) из заголовка раздела

2. **Кнопки из заголовка раздела**
   - Кнопки управления перенесены из заголовка в левую панель
   - Индикатор готовности перенесён из заголовка в левую панель

### Новые элементы

1. **Левая панель управления**
   - Ширина: `w-48` (192px)
   - Фиксированная ширина: `flex-shrink-0`
   - Вертикальное расположение: `flex flex-col gap-2`
   - Отступ сверху: `pt-4`

2. **Увеличенный индикатор готовности**
   - Размер: `text-4xl` (36px)
   - Центрирование: `text-center`
   - Цвет: зелёный для готовых, красный для неготовых

3. **Увеличенные кнопки**
   - Padding: `px-3 py-2` (вместо `px-3 py-1`)
   - Жирный шрифт: `font-semibold`

4. **Flex-контейнер для раздела**
   - Горизонтальное расположение: `flex gap-4`
   - Отступ между панелями: `gap-4` (16px)

5. **Адаптивный лист A4**
   - Максимальная ширина: `maxWidth: '210mm'`
   - Занимает оставшееся пространство: `flex-1`

## Преимущества нового интерфейса

### 1. Чистый дизайн
- Убраны визуальные разделители между разделами
- Каждый раздел выглядит как отдельный документ
- Больше пространства для содержимого

### 2. Удобство управления
- Кнопки всегда видны слева от содержимого
- Не нужно прокручивать заголовок для доступа к кнопкам
- Индикатор готовности крупнее и заметнее

### 3. Визуальное соответствие
- Интерфейс напоминает профессиональные редакторы документов
- Левая панель похожа на панель инструментов в Word
- Лист A4 выглядит как реальная страница документа

### 4. Эргономика
- Кнопки расположены в зоне досягаемости мыши
- Индикатор готовности виден без прокрутки
- Меньше движений мышью для управления разделами

## Размеры и отступы

### Левая панель
- Ширина: 192px (w-48)
- Отступ сверху: 16px (pt-4)
- Расстояние между кнопками: 8px (gap-2)
- Расстояние до листа A4: 16px (gap-4)

### Индикатор готовности
- Размер шрифта: 36px (text-4xl)
- Выравнивание: по центру
- Цвета:
  - Готов: зелёный (text-green-600)
  - Не готов: красный (text-red-500)

### Кнопки управления
- Padding: 12px горизонтально, 8px вертикально (px-3 py-2)
- Размер шрифта: 14px (text-sm)
- Жирный шрифт: font-semibold
- Скругление: rounded (4px)

### Лист A4
- Максимальная ширина: 210mm
- Минимальная высота: 297mm
- Поля: 20mm сверху/снизу, 30mm слева, 15mm справа
- Тень: shadow-lg
- Адаптивная ширина: flex-1

## Режим редактирования

При нажатии кнопки "✎ Редактировать" левая панель меняется:

**Обычный режим:**
```
┌──────────┐
│ ✓        │ ← Индикатор готовности
│          │
│ [Редакт] │
│ [Автог]  │
│ [Готово] │
└──────────┘
```

**Режим редактирования:**
```
┌──────────┐
│ ✓        │ ← Индикатор готовности
│          │
│ [Сохран] │
│ [Отмена] │
└──────────┘
```

Кнопки "Автогенерация" и "Готово" скрываются на время редактирования.
