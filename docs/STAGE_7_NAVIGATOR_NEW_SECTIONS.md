## Особенности реализации

### 1. Пустые подразделы
Оба новых раздела созданы с пустыми массивами `children: []`. Это означает:
- Разделы отображаются в навигаторе
- Не имеют подразделов (пока)
- Могут быть раскрыты/свернуты (но без эффекта, так как детей нет)

### 2. Иконки
- **ГЕОФИЗИКА**: 📡 (антенна/сигнал)
- **ПОЯСНИТЕЛЬНАЯ ЗАПИСКА**: 📝 (документ с карандашом)

### 3. Раскрытие по умолчанию
Оба раздела добавлены в начальное состояние `expanded`, поэтому они раскрыты по умолчанию при загрузке приложения.
