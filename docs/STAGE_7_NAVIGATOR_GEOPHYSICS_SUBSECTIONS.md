## Описание геофизических методов

### ВЭЗ (Вертикальное Электрическое Зондирование)
- **ID:** `vez`
- **Иконка:** 📊
- **Описание:** Метод электроразведки, основанный на исследовании кажущегося удельного электрического сопротивления горных пород по вертикали
- **Применение:** Определение глубины залегания водоносных горизонтов, границ между различными типами грунтов

### БТ (Буровая Томография)
- **ID:** `bt`
- **Иконка:** 📊
- **Описание:** Метод геофизических исследований между скважинами для изучения пространственного распределения физических свойств
- **Применение:** Детальное изучение геологического разреза, выявление зон повышенной трещиноватости

### Микросейсморайонирование
- **ID:** `microseismic`
- **Иконка:** 📊
- **Описание:** Метод изучения микросейсмических колебаний для оценки инженерно-геологических условий
- **Применение:** Оценка сейсмических условий территории, выявление зон с различными грунтовыми условиями
