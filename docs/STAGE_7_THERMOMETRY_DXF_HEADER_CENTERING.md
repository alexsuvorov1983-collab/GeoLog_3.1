# Центрирование шапки графика термометрии

## Описание изменения

Изменено выравнивание текста шапки графика (номер скважины и дата замера) для центрирования строго по центру от вертикальной оси глубин.

## Изменённый код

**Файл:** `src/utils/dxfGenerator.ts`  
**Строки:** 78-79

### Было:
```typescript
text(x0, yTop + 8, 3, row.name, 0, 0, 1);
text(x0, yTop + 4, 3, fmtDate(row.date, dateMode), 0, 0, 1);
```

### Стало:
```typescript
text(x0, yTop + 8, 3, row.name, 1, 1, 1);
text(x0, yTop + 4, 3, fmtDate(row.date, dateMode), 1, 1, 1);
```

## Объяснение параметров

Функция `text()` имеет следующие параметры:
```typescript
text(x, y, h, s, ah, av, color)
```

Где:
- `x, y` - координаты точки вставки
- `h` - высота текста
- `s` - строка текста
- `ah` - горизонтальное выравнивание (72)
- `av` - вертикальное выравнивание (73)
- `color` - цвет (62)

### Значения выравнивания:

**Горизонтальное (ah = 72):**
- `0` - по левому краю
- `1` - по центру
- `2` - по правому краю

**Вертикальное (av = 73):**
- `0` - по нижнему краю
- `1` - по середине
- `2` - по верхнему краю
