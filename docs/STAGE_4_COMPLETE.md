# Этап 4: Классификатор ГОСТ 25100

## Завершённые задачи

### 1. Модуль классификации грунтов (`SoilClassifier.ts`)

Создан полнофункциональный модуль автоматической классификации грунтов по ГОСТ 25100.

#### Реализованные функции:

**Классификация крупнообломочных грунтов:**
- Определение типа: валунный, галечниковый, гравийный
- Определение заполнителя (песчаный/пылевато-глинистый) при содержании >40%
- Формирование наименования по ГОСТ

**Классификация песчаных грунтов:**
- Определение вида песка по накопленным процентам фракций:
  - Гравелистый (≥50% фракции >2мм)
  - Крупный (≥50% фракции >1мм)
  - Средней крупности (≥50% фракции >0.5мм)
  - Мелкий (≥50% фракции >0.25мм)
  - Пылеватый (остальное)
- Определение плотности по коэффициенту пористости e:
  - Плотный (e < 0.55)
  - Средней плотности (0.55 ≤ e < 0.7)
  - Рыхлый (e ≥ 0.7)
- Определение водонасыщения по Sr:
  - Маловлажный (Sr < 0.5)
  - Влажный (0.5 ≤ Sr < 0.8)
  - Насыщенный водой (Sr ≥ 0.8)

**Классификация глинистых грунтов:**
- Определение вида по числу пластичности Ip:
  - Песок пылеватый (Ip ≤ 1)
  - Супесь (1 < Ip ≤ 7)
  - Суглинок (7 < Ip ≤ 17)
  - Глина (Ip > 17)
- Определение консистенции по показателю текучести IL:
  - Твёрдая (IL < 0)
  - Полутвёрдая (0 ≤ IL < 0.25)
  - Тугопластичная (0.25 ≤ IL < 0.5)
  - Мягкопластичная (0.5 ≤ IL < 0.75)
  - Текучепластичная (0.75 ≤ IL < 1)
  - Текучая (IL ≥ 1)

**Определение пучинистости:**
- Классификация по содержанию частиц <0.01мм и влажности:
  - Непучинистый (заполнитель <10%)
  - Слабопучинистый (10-30% заполнителя, W<15% или 30-50% заполнителя, W<20%)
  - Пучинистый (умеренные значения)
  - Сильнопучинистый (высокие значения влажности и заполнителя)

**Генерация наименования по ПолюсПроект:**
- Автоматическое формирование коммерческого наименования грунта
- Формат: "Песок [вид] [плотность]" или "[Тип] [консистенция]"

## Технические детали

### Архитектура модуля

```
SoilClassifier.ts
├── classifyCoarseFragmented() - классификация крупнообломочных
├── classifySandy() - классификация песчаных
├── classifyClayey() - классификация глинистых
├── classifyFrostSusceptibility() - определение пучинистости
├── generatePolyusProjectName() - генерация наименования
└── classifySoil() - главная функция классификации
```

### Интеграция с расчётами

Классификатор использует результаты расчётов из `SampleCalculations.ts`:
- `filler` - содержание заполнителя
- `sandInFine` - содержание песка в мелкоземе
- `e` - коэффициент пористости
- `Sr` - коэффициент водонасыщения
- `Ip` - число пластичности
- `IL` - показатель текучести

### Обработка ошибок

- Все функции классификации возвращают `Partial<ClassificationResult>`
- При недостатке данных возвращаются пустые значения
- Интеграция с системой валидации из Этапа 3
