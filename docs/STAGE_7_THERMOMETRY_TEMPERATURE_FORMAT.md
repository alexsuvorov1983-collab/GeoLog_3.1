# Этап 7: Термометрия - Форматирование температур до двух знаков

## Обзор
Изменено форматирование отображения значений температуры в таблице термометрии с одного знака после запятой на два знака.

## Изменения

### Файл: `src/components/ThermoTable.tsx`

#### Изменение 1: Строка 191
**Было:**
```typescript
setEditValue(temp !== undefined ? temp.toString() : '');
```

**Стало:**
```typescript
setEditValue(temp !== undefined ? temp.toFixed(2) : '');
```

**Описание:** При начале редактирования ячейки значение температуры отображается с двумя знаками после запятой.

#### Изменение 2: Строка 384 (горизонтальная ориентация)
**Было:**
```typescript
temp !== undefined ? temp.toFixed(1) : ''
```

**Стало:**
```typescript
temp !== undefined ? temp.toFixed(2) : ''
```

**Описание:** В горизонтальной ориентации таблицы температуры отображаются с двумя знаками после запятой.

#### Изменение 3: Строка 484 (вертикальная ориентация)
**Было:**
```typescript
temp !== undefined ? temp.toFixed(1) : ''
```

**Стало:**
```typescript
temp !== undefined ? temp.toFixed(2) : ''
```

**Описание:** В вертикальной ориентации таблицы температуры отображаются с двумя знаками после запятой.

## Результат

### До изменения:
- Температура 0.3 отображалась как "0.3"
- Температура 0.31 отображалась как "0.3" (округление)

### После изменения:
- Температура 0.3 отображается как "0.30"
- Температура 0.31 отображается как "0.31"
- Температура 12.5 отображается как "12.50"
- Температура -5.2 отображается как "-5.20"

## Преимущества

1. **Точность данных** - значения отображаются с большей точностью
2. **Единообразие** - все температуры имеют одинаковое количество знаков
3. **Удобство чтения** - легче сравнивать значения
4. **Соответствие стандартам** - два знака после запятой для температурных данных
