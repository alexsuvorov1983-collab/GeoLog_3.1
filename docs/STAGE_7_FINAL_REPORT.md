# Этап 7: Пояснительная записка - Финальный отчет

## Дата
2026-01-29

## Обзор этапа

На этапе 7 реализован полнофункциональный модуль "Пояснительная записка" с автоматической генерацией содержимого, редактированием разделов, экспортом в DOCX с ГОСТ-рамками и штампами, а также системой управления готовностью разделов.

## Реализованные функции

### 1. Структура документа (49 разделов)

**Предварительные разделы (6):**
- Обложка
- Титул
- Список исполнителей
- Содержание тома
- Состав отчётной документации
- Содержание

**Основные разделы (16):**
1. Введение
2. Изученность инженерно-геологических условий
3. Физико-географические и техногенные условия
4. Методики и технология выполнения работ
5. Геолого-геоморфологическое строение
   - 5.1. Стратиграфия
6. Гидрогеологические условия
7. Свойства грунтов
8. Специфические грунты
9. Геологические и инженерно-геологические процессы
10. Инженерно-геологические условия
11. Геофизические исследования
12. Уточнение исходной сейсмичности
13. Прогноз изменения инженерно-геологических условий
14. Сведения о контроле качества и приемке работ
15. Заключение
16. Список использованной литературы

**Приложения (26):**
- Приложения А-Я с таблицами и текстом
- Таблица регистрации изменений

### 2. Автогенерация содержимого

**Функция `generateSectionContent()`** автоматически заполняет разделы данными из проекта:

- **Раздел 4 (Методики):** объемы работ (скважины, пробы, термометрия)
- **Раздел 5.1 (Стратиграфия):** типы грунтов из soil_layers
- **Раздел 6 (Гидрогеология):** водопроявления из water_layers
- **Раздел 10 (Инженерно-геологические условия):** количество ИГЭ и вод
- **Раздел 14 (Контроль качества):** подробный текст о системе контроля
- **Раздел 15 (Заключение):** итоги и рекомендации
- **Раздел 16 (Литература):** 18 нормативных документов
- **Приложения Г-Я:** таблицы из boreholes, samples, waters

### 3. Плавающее окно ПЗ

**Компонент `ReportWindow.tsx`:**
- Перетаскивание за шапку
- Изменение размера за угол
- Сворачивание/разворачивание/закрытие
- Сохранение состояния в localStorage

**Интерфейс:**
- Левая панель: навигация по 49 разделам с scrollspy
- Правая панель: прокручиваемое содержимое
- Кнопки управления для каждого раздела:
  - ✎ Редактировать
  - ↺ Автогенерация
  - ✓ Готово / ✗ Не готово
  - 📷 Загрузить (для приложений)
  - 📄 Настройки листа

### 4. Система готовности разделов

**Логика:**
- По умолчанию все разделы не готовы (красный крестик ✗)
- Кнопка "✓ Готово" отмечает раздел как готовый (зеленая галочка ✓)
- Кнопка "✗ Не готово" отменяет готовность
- Состояние сохраняется в localStorage

**Индикаторы:**
- В левой панели навигации
- В правой панели у заголовков
- С tooltip при наведении

### 5. Форматирование A4

**Каждый раздел на отдельном листе:**
- Ширина: 210 мм (A4)
- Минимальная высота: 297 мм (A4)
- Поля: 20 мм сверху/снизу, 30 мм слева, 15 мм справа
- Шрифт: Times New Roman 12pt
- Межстрочный интервал: 1.5
- Разрыв страницы между разделами

### 6. Загрузка изображений

**Для 20 приложений (А, Б, В, Е, Ж, И, К, Л, М, Н, П, Р, С, Т, У, Х, Ц, Ш, Щ, Я):**
- Кнопка "📷 Загрузить"
- Поддержка множественной загрузки JPEG
- Каждое изображение на отдельном листе A4
- Изображения вписываются в лист (170×257 мм)
- Нумерация рисунков

### 7. Экспорт в DOCX

**Функция `generateDocx()`:**
- Титульный лист без номера страницы
- Таблица регистрации изменений
- Оглавление (TableOfContents)
- 49 разделов с заголовками
- Приложения с разрывами страниц

**Оформление:**
- Формат A4
- Поля: 30/15/20/20 мм
- Шрифт Times New Roman 14
- Полуторный интервал
- Колонтитулы с номерами страниц

### 8. ГОСТ-рамки и штампы

**Рамка страницы:**
- Таблица 1×1 в header
- Размеры: ширина страницы минус поля
- Границы: SINGLE, size 12, цвет черный
- Отображается на каждой странице

**Штампы:**
- **Большой штамп (форма 1):** 185×55 мм для титула
  - Организация
  - Название документа
  - Шифр проекта
- **Малый штамп (форма 2):** 185×15 мм для остальных листов
  - Шифр проекта
  - Номер страницы (PageNumber.CURRENT)
  - Общее количество страниц (PageNumber.TOTAL_PAGES)

**Настройки листа:**
- Формат: A4/A3
- Ориентация: portrait/landscape
- Тип штампа: big/small/none
- Сохранение в localStorage

### 9. Импорт из Excel

**Функция импорта термометрии:**
- Чтение файлов .xlsx/.xls
- Поиск листа "Термометрия"
- Парсинг дат (Excel serial number и строковые форматы)
- Чтение сетки глубин
- Создание сессий термометрии
- Предпросмотр с статистикой
- Подтверждение перед записью
