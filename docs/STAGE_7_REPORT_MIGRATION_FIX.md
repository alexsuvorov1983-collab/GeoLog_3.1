# Этап 7: Пояснительная записка - Исправление миграции готовности разделов

## Дата
2026-01-29

## Описание проблемы
При загрузке данных из localStorage поле `isReady` отсутствовало в старых данных, что приводило к неправильной инициализации состояния готовности разделов. Все разделы отображались как неготовые, даже если они должны были быть готовы по умолчанию (разделы 14 и 16).

## Причина
В функции инициализации состояния `sections` при загрузке из localStorage не выполнялась проверка наличия поля `isReady`. Старые данные, сохранённые до добавления этого поля, не содержали информацию о готовности разделов.

## Решение
Добавлена миграция данных при загрузке из localStorage:

```typescript
const [sections, setSections] = useState<SectionState[]>(() => {
  const saved = localStorage.getItem(SECTIONS_STORAGE_KEY);
  if (saved) {
    const parsed = JSON.parse(saved);
    // Миграция: если поле isReady отсутствует, установить по умолчанию
    return parsed.map((section: any) => {
      if (section.isReady === undefined) {
        const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
        return { ...section, isReady: isReadyByDefault };
      }
      return section;
    });
  }
  // Инициализация разделов автогенерацией
  // По умолчанию готовы только разделы 14 и 16
  return REPORT_SECTIONS.map(section => {
    const content = generateSectionContent(section.id);
    const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
    return {
      id: section.id,
      text: content.text,
      tableRows: content.tableRows,
      isEdited: false,
      isSaved: true,
      isReady: isReadyByDefault
    };
  });
});
```

## Логика миграции

1. **Загрузка из localStorage**: если данные сохранены, они парсятся
2. **Проверка поля `isReady`**: для каждого раздела проверяется наличие поля
3. **Установка по умолчанию**: если поле отсутствует, устанавливается значение по умолчанию:
   - Раздел 14 ("Сведения о контроле качества и приемке работ") → `isReady: true`
   - Раздел 16 ("Список использованной литературы") → `isReady: true`
   - Все остальные разделы → `isReady: false`
4. **Новая инициализация**: если данных в localStorage нет, создаются новые с правильными значениями по умолчанию
