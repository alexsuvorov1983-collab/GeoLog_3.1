# Этап 7: Термометрия - Добавление подписей температур в DXF

## Обзор

Добавлены подписи значений температуры у каждой вершины температурной полилинии в экспорте DXF, как в эталоне thermo2cad.html.

## Изменения

### 1. Функция форматирования температуры `fmtVal`

**Файл:** `src/utils/dxfGenerator.ts` (строка 39)

```typescript
const fmtVal = (t: number): string => (t < 0 ? t.toFixed(2) : ' ' + t.toFixed(2));
```

**Описание:**
- Форматирует температуру с 2 знаками после запятой
- Отрицательные значения: с минусом (например, "-5.20")
- Положительные значения: с пробелом-отступом (например, " 12.50")
- Выравнивание по ширине для визуальной согласованности

### 2. Подписи температур в функции `graph()`

**Файл:** `src/utils/dxfGenerator.ts` (строки 76-80)

```typescript
const pl: Array<[number, number]> = pts.map(p => [x0 + p.t * MM_PER_C, yTop - p.depth * mmPerM]);
poly(pl);
for (const p of pts) {
  const vx = x0 + p.t * MM_PER_C;
  const vy = yTop - p.depth * mmPerM;
  text(vx + 1.5, vy, 2.5, fmtVal(p.t), 0, 2);
}
```

**Описание:**
- После построения полилинии (`poly(pl)`) добавляется цикл
- Для каждой точки замера создаётся TEXT примитив
- Позиция: `(vx + 1.5, vy)` — смещение на 1.5 мм вправо от вершины
- Высота текста: 2.5 мм
- Выравнивание: `72=0` (по левому краю), `73=2` (по нижнему краю)
- Текст: отформатированное значение температуры через `fmtVal(p.t)`
- Слой: "ИИ_Термометрия", стиль: "THERMO", цвет: 7 (белый)

### 3. Обновление расчёта `$EXTMAX`

**Файл:** `src/utils/dxfGenerator.ts` (строка 82)

```typescript
if (x0 + W + 5 > maxX) { maxX = x0 + W + 5; }
```

**Описание:**
- Было: `if (x0 + W > maxX) { maxX = x0 + W; }`
- Стало: `if (x0 + W + 5 > maxX) { maxX = x0 + W + 5; }`
- Добавлено 5 мм запаса для подписей температур
- Гарантирует, что все подписи попадают в экстенты чертежа
- При расчёте `$EXTMAX` используется `maxX + 10`, что даёт дополнительный запас

**Параметры:**
- `8` — слой "ИИ_Термометрия"
- `7` — стиль "THERMO"
- `62` — цвет 7 (белый)
- `10/20/30` — координаты точки вставки
- `40` — высота текста 2.5 мм
- `1` — текст значения температуры
- `72` — горизонтальное выравнивание (0 = по левому краю)
- `73` — вертикальное выравнивание (2 = по нижнему краю)
- `11/21/31` — координаты точки выравнивания

## Пример генерации

**Входные данные:**
- Глубина: 5.0 м
- Температура: 12.50 °C
- Масштаб: 1:100 (mmPerM = 10)
- Позиция графика: x0 = 10, yTop = 0

**Расчёт координат:**
```
vx = 10 + 12.50 * 2 = 35.00 мм
vy = 0 - 5.0 * 10 = -50.00 мм
```

**TEXT примитив:**
```
Позиция: (35.00 + 1.5, -50.00) = (36.50, -50.00)
Текст: " 12.50" (с пробелом-отступом)
```

**Отрицательная температура:**
- Температура: -5.20 °C
- Текст: "-5.20" (с минусом)

## Раскладка и отступы

**Шаг между графиками:** 80 мм (STEP = 2 × W)

**Максимальная ширина графика:**
- Ось глубин: x0 = 10 мм
- Подписи глубин: x0 - 3 = 7 мм (слева)
- Температурная кривая: x0 + t × 2 мм
- Подписи температур: x0 + t × 2 + 1.5 мм (справа)
- При t = +12.5°C: 10 + 25 + 1.5 = 36.5 мм
- При t = -5.0°C: 10 - 10 + 1.5 = 1.5 мм

**Запас для подписей:**
- maxX = x0 + W + 5 = 10 + 40 + 5 = 55 мм
- $EXTMAX = maxX + 10 = 65 мм
- Гарантирует, что все подписи попадают в экстенты
