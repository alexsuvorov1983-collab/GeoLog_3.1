# Этап 7: Термометрия - Временное отключение температурной кривой

## Обзор

Временное отключение температурной кривой (POLYLINE) из DXF экспорта с возможностью быстрого включения через константу `DRAW_CURVE`. График теперь состоит только из табличных элементов: оси глубин, засечек, подписей глубин, значений температур и шапки.

## Изменения

### 1. Добавлена константа DRAW_CURVE

**Файл:** `src/utils/dxfGenerator.ts` (строка 15)

```typescript
const DRAW_CURVE = false;
```

**Описание:**
- Флаг для управления выводом температурной кривой
- При `false` — кривая не выводится (текущее состояние)
- При `true` — кривая выводится (для будущего использования)
- Позволяет быстро включить/выключить кривую изменением одной строки

### 2. Изменена позиция подписей температур

**Файл:** `src/utils/dxfGenerator.ts` (строка 75)

**Было:**
```typescript
text(x0 + 2, vy, 2.5, fmtVal(p.t), 0, 2);
```

**Стало:**
```typescript
text(x0 + 10, vy, 2.5, fmtVal(p.t), 0, 2);
```

**Описание:**
- Подписи температур перемещены на 10 мм правее оси глубин
- Раньше были на 2 мм (слишком близко к оси)
- Теперь создают отдельный столбец значений
- Улучшена читаемость и визуальное разделение

### 3. Обновлён расчёт экстентов

**Файл:** `src/utils/dxfGenerator.ts` (строка 79)

**Было:**
```typescript
if (x0 + W > maxX) { maxX = x0 + W; }
```

**Стало:**
```typescript
if (x0 + 10 + 15 > maxX) { maxX = x0 + 10 + 15; }
```

**Описание:**
- maxX = x0 + 10 (позиция подписей) + 15 (запас на текст)
- Гарантирует, что все подписи температур попадают в экстенты
- Учитывает столбец значений температур

## Состав графика (на каждую сессию)

### 1. Ось глубин
```typescript
line(x0, yTop, x0, yTop - H);
```
- Вертикальная линия от yTop до yTop-H
- Цвет 7 (белый)
- Слой "ИИ_Термометрия"

### 2. Засечки и подписи глубин
```typescript
for (const p of pts) {
  const y = yTop - p.depth * mmPerM;
  line(x0 - 2, y, x0, y);  // засечка
  text(x0 - 3, y, 2.5, p.depth.toFixed(1), 2, 1);  // подпись
}
```
- Засечка: LINE от (x0-2, y) до (x0, y)
- Подпись: TEXT на (x0-3, y), высота 2.5, выравнивание 72=2, 73=1
- Текст: глубина с 1 знаком после запятой

### 3. Значения температур
```typescript
for (const p of pts) {
  const vy = yTop - p.depth * mmPerM;
  text(x0 + 10, vy, 2.5, fmtVal(p.t), 0, 2);
}
```
- TEXT на (x0+10, vy), высота 2.5, выравнивание 72=0, 73=2
- Текст: температура с 2 знаками после запятой (fmtVal)
- Отрицательные значения с минусом, положительные с пробелом

### 4. Шапка
```typescript
text(x0, yTop + 8, 3, row.name, 0, 0);
text(x0, yTop + 4, 3, fmtDate(row.date, dateMode), 0, 0);
```
- Номер скважины: TEXT на (x0, yTop+8), высота 3
- Дата: TEXT на (x0, yTop+4), высота 3
- Формат даты зависит от dateMode

### 5. Температурная кривая (ОТКЛЮЧЕНА)
```typescript
// const pl: Array<[number, number]> = pts.map(p => [x0 + p.t * MM_PER_C, yTop - p.depth * mmPerM]);
// poly(pl);
```
- Закомментировано
- Функция poly() определена, но не вызывается
- Можно включить изменением DRAW_CURVE на true

## Раскладка

### Одиночный масштаб (1:100 или 1:200)
- Графики в ряд с шагом 80 мм (STEP = 2 × W)
- mmPerM = 10 для 1:100, mmPerM = 5 для 1:200

### Режим "оба"
- 1:100 слева (X0, y)
- 1:200 справа (X0 + GAP, y)
- GAP = 165 мм
- Следующая сессия ниже с отступом VGAP = 25 мм

### Экстенты
- maxX = x0 + 10 + 15 = x0 + 25 мм
- $EXTMAX = maxX + 10 = x0 + 35 мм
- Гарантирует попадание всех подписей в экстенты

```typescript

```
