# Этап 7: Термометрия - Добавление левых засечек для глубины

## Дата
2026-01-29

## Описание изменения
Добавлены риски (засечки) слева от основной вертикальной полилинии напротив каждой глубины замера, симметрично правым засечкам для температуры.

## Проблема
Ранее засечки были только справа от оси (для температуры), а слева от оси (для глубины) их не было. Это создавало визуальную асимметрию.

## Решение
Добавлена левая засечка длиной 2 мм от x0-2 до x0 того же красного цвета (color=1), что и правая засечка.

## Изменения в коде

### Файл: `src/utils/dxfGenerator.ts`

**Строка 71:**

**Было:**
```typescript
line(x0, y, x0 + 2, y, 1);
```

**Стало:**
```typescript
line(x0 - 2, y, x0, y, 1);
line(x0, y, x0 + 2, y, 1);
```

## Результат

Теперь засечки симметричны с обеих сторон от вертикальной оси:

```
До изменения:
    С-1
  15.03.2024
    |
  0.0 |→→|  10.00  ← засечка только справа
    |
  2.5 |→→|   8.50  ← засечка только справа
    |
  5.0 |→→|  12.50  ← засечка только справа
    |

После изменения:
    С-1
  15.03.2024
    |
  0.0 ←|→→|  10.00  ← засечки с обеих сторон
    |
  2.5 ←|→→|   8.50  ← засечки с обеих сторон
    |
  5.0 ←|→→|  12.50  ← засечки с обеих сторон
    |
```

## Структура графика

```
|← 2 мм →|← 2 мм →|← 2 мм →|
         |
    Подписи   Ось    Засечки  Значения
    глубин    глубин  глубины  температур
   (x0-3)    (x0)   (x0-2→x0) (x0→x0+2) (x0+4)
   чёрные    чёрная  красные   красные    красные
```

**Горизонтальные позиции:**
- x0 - 3 мм: подписи глубин (чёрные)
- x0 - 2 мм → x0: левая засечка (красная, 2 мм)
- x0: вертикальная ось глубин (чёрная)
- x0 → x0 + 2 мм: правая засечка (красная, 2 мм)
- x0 + 4 мм: значения температур (красные)
