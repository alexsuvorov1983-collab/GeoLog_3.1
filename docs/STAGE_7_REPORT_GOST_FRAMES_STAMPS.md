# Этап 7: Пояснительная записка - Полная реализация ГОСТ-рамок и штампов

## Дата
2026-01-29

## Описание реализации

Полностью реализована генерация DOCX файлов с ГОСТ-рамками и штампами согласно требованиям ГОСТ 2.104 и ГОСТ Р 21.1101.

## Реализованные функции

### 1. Модель данных

**PageSettings** - настройки листа для каждого раздела:
```typescript
{
  format: 'A4' | 'A3';
  orientation: 'portrait' | 'landscape';
  stamp: 'big' | 'small' | 'none';
}
```

**StampSettings** - реквизиты штампа:
```typescript
{
  organization: string;
  documentName: string;
  code: string;
  stage: string;
  developer: string;
  developerDate: string;
  checker: string;
  checkerDate: string;
  normControl: string;
  normControlDate: string;
  approver: string;
  approverDate: string;
  totalSheets: number;
}
```

### 2. Диалоги настроек

**PageSettingsDialog** - диалог выбора формата листа:
- Формат: A4 (210×297) или A3 (297×420)
- Ориентация: вертикальная или горизонтальная
- Тип штампа: большой, малый или без штампа
- Предпросмотр текущих настроек

**StampSettingsDialog** - диалог редактирования реквизитов штампа:
- Организация
- Название документа
- Шифр проекта
- Стадия документации
- Ответственные лица (Разработал, Проверил, Н.контр., Утвердил) с датами
- Общее количество листов

### 3. Генерация DOCX с ГОСТ-рамками

**Функция createFrame()** - создание рамки:
- Таблица 1×1 с чёрными границами 1пт
- Размеры по ГОСТ Р 21.1101:
  - Левое поле: 20 мм
  - Правое поле: 5 мм
  - Верхнее поле: 5 мм
  - Нижнее поле: 5 мм
- Размещается в header каждой секции

**Функция createBigStamp()** - большой штамп (форма 1):
- Размеры: 185×55 мм
- Содержит:
  - Организация
  - Название документа
  - Шифр проекта
- Размещается в footer первой секции (титул)

**Функция createSmallStamp()** - малый штамп (форма 2):
- Размеры: 185×15 мм
- Содержит:
  - Шифр проекта
  - Номер текущего листа
  - Общее количество листов
- Размещается в footer всех остальных секций

### 4. Настройки страниц

**Функция createSection()** - создание секции документа:
- Отдельная секция для каждого раздела
- Настройки страницы согласно PageSettings:
  - A4 portrait: 210×297 мм
  - A4 landscape: 297×210 мм
  - A3 portrait: 297×420 мм
  - A3 landscape: 420×297 мм
- Поля страницы по ГОСТ Р 21.1101
- Header с рамкой
- Footer со штампом (big/small/none)

### 5. Значения по умолчанию

**Формат листов:**
- Титул: A4, portrait, big stamp
- Приложения Д, Г, Х, Ц: A3, landscape, small stamp (широкие таблицы)
- Все остальные: A4, portrait, small stamp

**Реквизиты штампа:**
- Организация: ООО "ГеоСтройСистема"
- Шифр: ЕС/4194/95-05/23/94-ГСС-УПН-ЯНГКМ-ИГИ
- Стадия: Рабочая документация

### 6. Сохранение настроек

- `pageSettings` сохраняется в localStorage под ключом `geolog_report_page_settings`
- `stampSettings` сохраняется в localStorage под ключом `geolog_report_stamp_settings`
- Настройки переживают перезагрузку страницы

### 7. Интерфейс пользователя

**Кнопка "📋 Штамп" в шапке окна:**
- Открывает диалог редактирования реквизитов штампа
- Доступна всегда

**Кнопка "📄" в навигации:**
- Открывает диалог настроек листа для конкретного раздела
- Доступна для каждого раздела
- Показывает текущие настройки в tooltip

## Технические детали

### Размеры и единицы измерения

**Библиотека docx использует:**
- TWIPs (1/20 точки) для внутренних размеров
- `convertMillimetersToTwip()` для конвертации миллиметров в TWIPs
- 1 мм = 56.69 TWIPs

**Размеры страниц:**
- A4: 210×297 мм = 11907×16840 TWIPs
- A3: 297×420 мм = 16840×23814 TWIPs

**Поля рамки:**
- Левое: 20 мм = 1134 TWIPs
- Правое: 5 мм = 283 TWIPs
- Верхнее: 5 мм = 283 TWIPs
- Нижнее: 5 мм = 283 TWIPs

**Размеры штампов:**
- Большой: 185×55 мм = 10490×3118 TWIPs
- Малый: 185×15 мм = 10490×850 TWIPs

### Структура документа

```
Документ
├─ Секция 1: Титул (A4 portrait, big stamp)
│  ├─ Header: рамка
│  └─ Footer: большой штамп
├─ Секция 2: Раздел 1 (A4 portrait, small stamp)
│  ├─ Header: рамка
│  └─ Footer: малый штамп с номером страницы
├─ Секция 3: Раздел 2 (A4 portrait, small stamp)
│  ├─ Header: рамка
│  └─ Footer: малый штамп с номером страницы
...
├─ Секция N: Приложение Д (A3 landscape, small stamp)
│  ├─ Header: рамка
│  └─ Footer: малый штамп с номером страницы
...
└─ Секция 49: Таблица регистрации (A4 portrait, small stamp)
   ├─ Header: рамка
   └─ Footer: малый штамп с номером страницы
```

### Сквозная нумерация

- Каждая секция имеет свой номер страницы
- Нумерация сквозная по всему документу
- Титул считается листом 1, но номер на нём не печатается (большой штамп вместо номера)
- Малый штамп содержит: "шифр — Лист X — Листов Y"
