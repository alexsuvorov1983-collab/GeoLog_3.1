# Ручная отметка готовности разделов в пояснительной записке

## Дата
2026-01-29

## Описание изменения
Изменена логика определения готовности разделов в модуле "Пояснительная записка". Теперь по умолчанию готовы только разделы 14 и 16, а для остальных разделов и приложений добавлена кнопка "Готово" для ручной отметки готовности.

## Изменения в логике

### Старая логика
Раздел считался готовым, если:
- Есть непустой текст, **ИЛИ**
- Есть таблица с данными

### Новая логика
Раздел считается готовым, только если:
- Поле `isReady` установлено в `true` (вручную пользователем)

### По умолчанию готовые разделы
При первой инициализации документа автоматически готовы только:
- **Раздел 14** - "Сведения о контроле качества и приемке работ"
- **Раздел 16** - "Список использованной литературы"

Все остальные разделы и приложения по умолчанию отмечены как неготовые (красный крестик ✗).

## Реализация

### Изменение интерфейса SectionState

Добавлено поле `isReady`:

```typescript
interface SectionState {
  id: string;
  text?: string;
  tableRows?: string[][];
  isEdited: boolean;
  isSaved: boolean;
  isReady: boolean;  // НОВОЕ ПОЛЕ
}
```

### Инициализация разделов

```typescript
return REPORT_SECTIONS.map(section => {
  const content = generateSectionContent(section.id);
  const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
  return {
    id: section.id,
    text: content.text,
    tableRows: content.tableRows,
    isEdited: false,
    isSaved: true,
    isReady: isReadyByDefault  // Только разделы 14 и 16 готовы по умолчанию
  };
});
```

### Функция проверки готовности

```typescript
const isSectionReady = (sectionState: SectionState | undefined): boolean => {
  if (!sectionState) return false;
  
  // Раздел готов, если явно отмечен как готовый
  return sectionState.isReady;
};
```

### Функция отметки раздела как готового

```typescript
const markSectionAsReady = (sectionId: string) => {
  setSections(prev => prev.map(s => 
    s.id === sectionId 
      ? { ...s, isReady: true }
      : s
  ));
  Journal.logEvent('info', `Раздел ${sectionId} отмечен как готовый`, 'report.section_ready');
};
```

### Кнопка "Готово"

Добавлена в блок кнопок управления разделом (только когда раздел не в режиме редактирования и ещё не готов):

```tsx
{!isReady && (
  <button
    onClick={() => markSectionAsReady(section.id)}
    className="px-3 py-1 bg-green-500 hover:bg-green-600 text-white rounded text-sm font-semibold"
    title="Отметить раздел как готовый"
  >
    ✓ Готово
  </button>
)}
```

## Визуальное оформление

### Индикаторы готовности
- **Зелёная галочка (✓)** — раздел готов (отмечен вручную или по умолчанию)
- **Красный крестик (✗)** — раздел не готов

### Кнопка "Готово"
- Цвет: зелёный (`bg-green-500`)
- Hover: более тёмный зелёный (`hover:bg-green-600`)
- Текст: "✓ Готово"
- Отображается только для неготовых разделов
- Скрывается после нажатия (раздел становится готовым)

### Расположение кнопок
Порядок кнопок в режиме просмотра (не редактирования):
1. ✎ Редактировать (синяя)
2. ↺ Автогенерация (оранжевая)
3. ✓ Готово (зелёная) — только если раздел не готов

## Сохранение состояния

Состояние готовности разделов сохраняется в `localStorage` вместе с остальными данными разделов:
- Ключ: `geolog_report_sections`
- При загрузке документа состояние готовности восстанавливается
- При отметке раздела как готового изменение сохраняется автоматически

## Примеры использования

### Пример 1: Новый документ
1. Открыть окно "Пояснительная записка"
2. Все разделы кроме 14 и 16 отмечены красным крестиком (✗)
3. Разделы 14 и 16 отмечены зелёной галочкой (✓)

### Пример 2: Отметка раздела как готового
1. Перейти к разделу 1 "Введение"
2. Раздел отмечен красным крестиком (✗)
3. Нажать кнопку "✓ Готово"
4. Раздел отмечается зелёной галочкой (✓)
5. Кнопка "Готово" скрывается

### Пример 3: Редактирование готового раздела
1. Раздел 1 отмечен как готовый (✓)
2. Нажать "✎ Редактировать"
3. Внести изменения в текст
4. Нажать "✓ Сохранить"
5. Раздел остаётся готовым (✓)

### Пример 4: Сброс к автогенерации
1. Раздел отмечен как готовый (✓)
2. Нажать "↺ Автогенерация"
3. Раздел перегенерируется из данных проекта
4. Раздел остаётся готовым (✓) — состояние готовности не сбрасывается
