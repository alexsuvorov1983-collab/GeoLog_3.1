# Этап 7: Пояснительная записка - Отображение изображений на отдельных листах A4

## Дата
2026-01-29

## Описание изменения
Изменено отображение загруженных изображений в приложениях пояснительной записки. Теперь каждое изображение отображается на отдельном листе формата A4, как отдельная страница документа.

## Что изменилось

### Старое отображение
- Изображения отображались в сетке 2 колонки
- Все изображения на одной странице
- Компактное отображение

```
Загруженные изображения:
┌─────────┐  ┌─────────┐
│  [img1] │  │  [img2] │
└─────────┘  └─────────┘
┌─────────┐  ┌─────────┐
│  [img3] │  │  [img4] │
└─────────┘  └─────────┘
```

### Новое отображение
- Каждое изображение на отдельном листе A4
- Разрыв страницы между изображениями (page-break-before)
- Центрирование изображения на листе
- Номер изображения под листом

```
Загруженные изображения:

┌─────────────────────┐
│                     │
│                     │
│      [img1]         │  ← Лист A4
│                     │
│                     │
└─────────────────────┘
      Рисунок 1

┌─────────────────────┐
│                     │
│                     │
│      [img2]         │  ← Лист A4
│                     │
│                     │
└─────────────────────┘
      Рисунок 2
```

## Реализация

### Структура компонента

```tsx
{uploadedImages[section.id].map((image, idx) => (
  <div key={idx} className="relative group">
    {/* Лист A4 для изображения */}
    <div 
      className="bg-white shadow-lg mx-auto"
      style={{
        width: '210mm',
        minHeight: '297mm',
        padding: '20mm',
        pageBreakBefore: 'always',
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center'
      }}
    >
      <img 
        src={image} 
        alt={`Изображение ${idx + 1}`}
        className="max-w-full max-h-full object-contain"
      />
    </div>
    
    {/* Кнопка удаления */}
    <button
      onClick={() => handleImageDelete(section.id, idx)}
      className="absolute top-4 right-4 ..."
    >
      ×
    </button>
    
    {/* Номер изображения */}
    <div className="text-center text-sm text-gray-500 mt-2">
      Рисунок {idx + 1}
    </div>
  </div>
))}
```

### Параметры листа A4

**Размеры:**
- Ширина: 210mm (стандарт A4)
- Минимальная высота: 297mm (стандарт A4)
- Поля: 20mm со всех сторон

**Стиль:**
- Белый фон (bg-white)
- Тень для визуального разделения (shadow-lg)
- Центрирование по горизонтали (mx-auto)
- Разрыв страницы при печати (pageBreakBefore: 'always')

**Размещение изображения:**
- Flexbox для центрирования (display: 'flex')
- Выравнивание по центру (alignItems: 'center', justifyContent: 'center')
- Адаптивный размер (max-w-full, max-h-full)
- Сохранение пропорций (object-contain)

### Дополнительные элементы

**Кнопка удаления:**
- Позиция: absolute top-4 right-4
- Размер: 32x32px (w-8 h-8)
- Цвет: красный (bg-red-500)
- Появляется при наведении (opacity-0 group-hover:opacity-100)
- Тень для выделения (shadow-lg)

**Номер изображения:**
- Позиция: под листом A4
- Текст: "Рисунок 1", "Рисунок 2" и т.д.
- Цвет: серый (text-gray-500)
- Размер: 14px (text-sm)
- Выравнивание: по центру (text-center)

## Преимущества нового отображения

### 1. Визуальное соответствие документу
- Каждое изображение на отдельном листе
- Соответствует стандарту оформления приложений
- Готово к печати без дополнительной форматировки

### 2. Удобство просмотра
- Изображения не перекрываются
- Каждое изображение хорошо видно
- Легко ориентироваться между изображениями

### 3. Профессиональный вид
- Разрывы страниц между изображениями
- Нумерация рисунков
- Центрирование на листе

### 4. Готовность к экспорту
- При экспорте в DOCX/PDF каждое изображение будет на отдельной странице
- Не требуется дополнительная форматировка
- Соответствует стандартам оформления документации

## Применение

### Режим редактирования
- Изображения отображаются на отдельных листах A4
- Можно добавлять новые изображения
- Можно удалять существующие изображения
- Кнопка удаления появляется при наведении

### Режим просмотра
- Изображения отображаются на отдельных листах A4
- Нумерация рисунков
- Нельзя редактировать или удалять

### Печать
- Каждое изображение печатается на отдельной странице
- Автоматические разрывы страниц
- Правильные поля для печати
