# Исправление проблемы с перетаскиванием окна "Пояснительная записка"

## Дата
2026-01-29

## Проблема
Окно "Пояснительная записка" не перемещалось мышью при попытке перетаскивания за шапку.

## Причина
В файле `src/components/ReportWindow.tsx` в `useEffect` (строки 111-143) было условие:

```javascript
if (isDragging.current || isResizing.current) {
  document.addEventListener('mousemove', handleMouseMove);
  document.addEventListener('mouseup', handleMouseUp);
}
```

Это условие проверялось **только при первом рендере компонента**, когда `isDragging.current` и `isResizing.current` равны `false`. Поэтому обработчики событий `mousemove` и `mouseup` **никогда не добавлялись** к `document`.

## Решение
Убрал условие и теперь обработчики добавляются всегда:

```javascript
// Всегда добавляем обработчики, проверка флагов внутри них
document.addEventListener('mousemove', handleMouseMove);
document.addEventListener('mouseup', handleMouseUp);
```

Проверка флагов `isDragging.current` и `isResizing.current` происходит внутри самих обработчиков, что является правильным подходом.

## Изменённый файл
- `src/components/ReportWindow.tsx` (строки 111-143)

## Как это работает теперь

1. **Пользователь нажимает на шапку окна** → вызывается `handleMouseDown(e, 'drag')`
2. **Устанавливается флаг** `isDragging.current = true` и вычисляется смещение
3. **Пользователь перемещает мышь** → срабатывает `handleMouseMove` (всегда добавлен к document)
4. **Проверяется флаг** `if (isDragging.current)` → обновляется позиция окна
5. **Пользователь отпускает кнопку мыши** → срабатывает `handleMouseUp` (всегда добавлен к document)
6. **Сбрасывается флаг** `isDragging.current = false`
