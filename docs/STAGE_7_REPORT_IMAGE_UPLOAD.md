## Реализованные функции

### 1. Состояние для хранения изображений
Добавлено состояние `uploadedImages` для хранения загруженных изображений по разделам:

```typescript
const [uploadedImages, setUploadedImages] = useState<Record<string, string[]>>({});
```

### 2. Функция загрузки изображений
Реализована функция `handleImageUpload` для обработки загрузки файлов:

```typescript
const handleImageUpload = (sectionId: string, event: React.ChangeEvent<HTMLInputElement>) => {
  const files = event.target.files;
  if (!files) return;

  Array.from(files).forEach(file => {
    if (file.type === 'image/jpeg' || file.type === 'image/jpg') {
      const reader = new FileReader();
      reader.onload = (e) => {
        const result = e.target?.result as string;
        setUploadedImages(prev => ({
          ...prev,
          [sectionId]: [...(prev[sectionId] || []), result]
        }));
      };
      reader.readAsDataURL(file);
    }
  });
  
  event.target.value = '';
};
```

**Особенности:**
- Поддержка множественной загрузки файлов
- Фильтрация только JPEG файлов
- Конвертация в base64 для хранения
- Сброс input для повторной загрузки

### 3. Функция удаления изображений
Реализована функция `handleImageDelete` для удаления загруженных изображений:

```typescript
const handleImageDelete = (sectionId: string, imageIndex: number) => {
  setUploadedImages(prev => ({
    ...prev,
    [sectionId]: prev[sectionId]?.filter((_, idx) => idx !== imageIndex) || []
  }));
};
```

### 5. Кнопка загрузки в интерфейсе
Добавлена кнопка "📷 Загрузить" в левую панель управления для указанных приложений:

```tsx
{imageUploadSections.includes(section.id) && (
  <label className="px-3 py-2 bg-purple-500 hover:bg-purple-600 text-white rounded text-sm font-semibold cursor-pointer text-center">
```

- Скрытый input для выбора файлов

### 6. Отображение загруженных изображений
Добавлено отображение загруженных изображений в обоих режимах (редактирование и просмотр):

```tsx
{uploadedImages[section.id] && uploadedImages[section.id].length > 0 && (
  <div className="space-y-4 mt-6">
    <h3 className="text-sm font-semibold text-gray-700">Загруженные изображения:</h3>
    <div className="grid grid-cols-2 gap-4">
      {uploadedImages[section.id].map((image, idx) => (
        <div key={idx} className="relative group">
          <img 
            src={image} 
            alt={`Изображение ${idx + 1}`}
            className="w-full h-auto border border-gray-300 rounded"
          />
          <button
            onClick={() => handleImageDelete(section.id, idx)}
            className="absolute top-2 right-2 bg-red-500 hover:bg-red-600 text-white rounded-full w-6 h-6 flex items-center justify-center opacity-0 group-hover:opacity-100 transition-opacity"
            title="Удалить изображение"
          >
            ×
          </button>
        </div>
      ))}
    </div>
  </div>
)}
```

**Особенности:**
- Сетка 2 колонки для отображения изображений
- Адаптивный размер изображений
- Кнопка удаления при наведении (hover)
- Плавная анимация появления кнопки удаления

## Технические детали

### Хранение изображений
- Изображения хранятся в состоянии компонента в формате base64
- Ключ: ID раздела
- Значение: массив строк base64

### Ограничения
- Поддерживаемые форматы: JPEG, JPG
- Множественная загрузка: да
- Размер файлов: ограничен браузером (обычно до нескольких МБ)

### Производительность
- Base64 кодирование увеличивает размер данных на ~33%
- Рекомендуется загружать изображения разумного размера
- Для больших документов可以考虑 использование серверного хранилища
