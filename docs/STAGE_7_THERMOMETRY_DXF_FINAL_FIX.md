# Финальное исправление экспорта DXF

## Проблема
Экспорт в DXF не работал из-за ошибки TypeScript TS2322 и неправильного цвета слоя.

## Диагностика

### Ошибка 1: TypeScript TS2322
```
Type 'ArrayBuffer | SharedArrayBuffer' is not assignable to type 'BlobPart'
```

**Причина:** В функции `downloadDXF` использовался неправильный способ создания Blob:
```typescript
// НЕПРАВИЛЬНО
const arrayBuffer = encoded.buffer.slice(...) as ArrayBuffer;
const blob = new Blob([arrayBuffer as unknown as BlobPart], ...);
```

### Ошибка 2: Неправильный цвет слоя
Слой «ИИ_Термометрия» имел цвет 1 (красный) вместо цвета 7 (белый).

**Причина:** В функции `tablesSection` было указано `62\n1` вместо `62\n7`.

## Решение

### 1. Исправление downloadDXF

**Файл:** `src/utils/dxfGenerator.ts`

**Было:**
```typescript
const arrayBuffer = encoded.buffer.slice(
  encoded.byteOffset, 
  encoded.byteOffset + encoded.byteLength
) as ArrayBuffer;
const blob = new Blob([arrayBuffer as unknown as BlobPart], { type: 'application/dxf' });
```

**Стало:**
```typescript
// Используем slice() для создания копии и получаем её buffer
const arrayBuffer = encoded.slice().buffer;
const blob = new Blob([arrayBuffer], { type: 'application/dxf' });
```

**Объяснение:**
- `encoded.slice()` создаёт копию Uint8Array
- `.buffer` возвращает ArrayBuffer этой копии
- ArrayBuffer является валидным BlobPart
- TypeScript принимает это без приведения типов

### 2. Исправление tablesSection

**Файл:** `src/utils/dxfGenerator.ts`

**Было:**
```typescript
`0\nLAYER\n2\n${LAYER_NAME}\n70\n0\n62\n1\n6\nCONTINUOUS\n`
```

**Стало:**
```typescript
`0\nLAYER\n2\n${LAYER_NAME}\n70\n0\n62\n7\n6\nCONTINUOUS\n`
```

**Объяснение:**
- Код 62 определяет цвет слоя
- 1 = красный, 7 = белый
- По требованиям AutoCAD слой должен быть белым (цвет 7)

## Кодировка CP1251

Функция `toCp1251` кодирует:
- Русские буквы: А-Я (0xC0-0xDF), а-я (0xE0-0xFF)
- Специальные символы: Ё (0xA8), ё (0xB8), № (0xB9), ° (0xB0)
- Типографские символы: – (0x96), — (0x97), « (0xAB), » (0xBB)
- Неотображаемые символы: ? (0x3F)
