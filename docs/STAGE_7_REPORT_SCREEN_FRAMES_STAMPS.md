# Этап 7: Пояснительная записка - Отображение ГОСТ-рамок и штампов на экране

## Дата
2026-01-29

## Задача
Добавить отображение ГОСТ-рамок и штампов на экранных листах в окне "Пояснительная записка" (компонент ReportWindow.tsx).

## Решение

### 1. Создан компонент SheetStamp.tsx

Компонент отображает штампы двух типов:

**Малый штамп (185×15 мм):**
- Расположение: absolute, bottom 5mm, right 5mm
- Левая часть (40%): пустые графы "Изм. Лист №докум. Подп. Дата"
- Правая часть (60%): шифр, "Лист X", "Листов Y"
- Шрифт: 8pt Times New Roman
- Границы ячеек: 0.3mm solid #000

**Большой штамп (185×55 мм):**
- Расположение: absolute, bottom 5mm, right 5mm
- Организация (жирный шрифт)
- Название документа
- Шифр проекта
- Роли и даты (Разработал, Проверил, Н.контр., Утвердил)
- Стадия, "Лист 1", "Листов Y"
- Шрифт: 8pt Times New Roman
- Границы: 0.3mm solid #000

### 2. Создан компонент PageSheet.tsx

Компонент отображает лист формата A4/A3 с ГОСТ-рамкой и штампом:

**Размеры страниц:**
- A4 portrait: 210×297 мм
- A4 landscape: 297×210 мм
- A3 portrait: 297×420 мм
- A3 landscape: 420×297 мм

**Рамка:**
- Position: absolute
- Отступы от краёв листа: left 20mm, right 5mm, top 5mm, bottom 5mm
- Border: 0.5mm solid #000

**Масштабирование:**
- Используется CSS transform: scale(k)
- k = ширина контейнера / ширина листа в px
- transform-origin: top left
- Высота обёртки = высота листа × k
- ResizeObserver для отслеживания изменения размера контейнера

**Контент раздела:**
- Padding: top 10mm, bottom 20mm, left 25mm, right 10mm
- Текст ВНУТРИ рамки с отступами
- Шрифт: Times New Roman, 12pt, line-height 1.5

**Штамп:**
- Отображается поверх контента
- Расположение: внизу внутри рамки
- Тип штампа зависит от pageSettings.stamp ('big', 'small', 'none')

### 3. Интеграция в ReportWindow.tsx

**Изменения:**
- Импортирован компонент PageSheet
- Заменён текущий div листа A4 на компонент PageSheet
- Переданы пропсы:
  - pageSettings: настройки листа для раздела
  - stampSettings: реквизиты штампа
  - pageNumber: порядковый номер раздела (1-based)
  - totalPages: общее количество разделов
  - children: контент раздела (заголовок, текст, таблицы, изображения)

**Реактивность:**
- Превью читает pageSettings и stampSettings из состояния ReportWindow
- После сохранения в диалоге настроек листа или диалоге "Штамп" лист перерисовывается сразу
- Формат, ориентация, штамп, реквизиты обновляются мгновенно

## Технические детали

### Масштабирование

```typescript
const updateScale = () => {
  if (!containerRef.current) return;
  
  const containerWidth = containerRef.current.offsetWidth;
  const newScale = containerWidth / sheetWidth;
  setScale(newScale);
};
```

- Используется ResizeObserver для отслеживания изменения размера контейнера
- Также обновляется при изменении размера окна (window.addEventListener('resize'))
- Обновляется при изменении формата/ориентации листа

### Размеры рамки

```typescript
const frameWidth = sheetWidth - FRAME_MARGINS.left - FRAME_MARGINS.right;
const frameHeight = sheetHeight - FRAME_MARGINS.top - FRAME_MARGINS.bottom;
```

- FRAME_MARGINS: { left: 20, right: 5, top: 5, bottom: 5 } мм
- Рамка рисуется внутри листа с отступами

### Нумерация страниц

```typescript
pageNumber={REPORT_SECTIONS.findIndex(s => s.id === section.id) + 1}
totalPages={REPORT_SECTIONS.length}
```

- X = порядковый номер раздела в REPORT_SECTIONS (1-based)
- Y = REPORT_SECTIONS.length (49 разделов)
- В DOCX нумерация остаётся полями Word — не меняется
