# Этап 7: Пояснительная записка - Диагностика проблемы с готовностью разделов

## Дата
2026-01-29

## Описание проблемы
Пользователь сообщает, что по умолчанию готовы только разделы 14 и 16, но индикаторы готовности отображаются неправильно. Проблема связана с данными в localStorage.

## Возможные причины

### Причина 1: Старые данные в localStorage
Если в localStorage уже есть данные из предыдущих версий приложения, они могут содержать неправильные значения поля `isReady`. Например:
- Все разделы могут быть отмечены как готовые (`isReady: true`)
- Или все разделы могут быть отмечены как неготовые (`isReady: false`)

В этом случае миграция не выполняется, потому что поле `isReady` уже присутствует в данных.

### Причина 2: Неправильная инициализация
Если при первой загрузке (когда нет данных в localStorage) инициализация происходит неправильно, все разделы могут быть отмечены как готовые или неготовые.

### Причина 3: Ошибка в логике отображения
Индикаторы готовности могут отображаться неправильно из-за ошибки в функции `isSectionReady` или в коде отображения.

## Решение проблемы

### Если проблема в старых данных в localStorage

**Решение 1: Очистить localStorage**
```javascript
localStorage.removeItem('geolog_report_sections');
```
Затем перезагрузить страницу.

**Решение 2: Добавить версию данных**
Можно добавить версию данных в localStorage и при изменении версии выполнять миграцию. Но это усложняет код.

**Решение 3: Добавить кнопку сброса**
Можно добавить в интерфейс кнопку "Сбросить настройки готовности", которая очистит поле `isReady` для всех разделов и установит значения по умолчанию.

### Если проблема в инициализации

Проверьте код инициализации в `ReportWindow.tsx`:

```typescript
const [sections, setSections] = useState<SectionState[]>(() => {
  const saved = localStorage.getItem(SECTIONS_STORAGE_KEY);
  if (saved) {
    const parsed = JSON.parse(saved);
    
    // Проверяем, нужна ли миграция (если у первого раздела нет поля isReady)
    const needsMigration = parsed.length > 0 && parsed[0].isReady === undefined;
    
    if (needsMigration) {
      // Миграция: установить isReady по умолчанию
      const migrated = parsed.map((section: any) => {
        const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
        return { ...section, isReady: isReadyByDefault };
      });
      return migrated;
    } else {
      // Данные актуальны, миграция не требуется
      return parsed;
    }
  }
  
  // Инициализация новых разделов
  return REPORT_SECTIONS.map(section => {
    const content = generateSectionContent(section.id);
    const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
    return {
      id: section.id,
      text: content.text,
      tableRows: content.tableRows,
      isEdited: false,
      isSaved: true,
      isReady: isReadyByDefault
    };
  });
});
```

**Проверьте:**
- При первой загрузке (нет данных в localStorage) — разделы 14 и 16 должны иметь `isReady: true`, остальные — `isReady: false`
- При загрузке из localStorage — должны использоваться сохранённые значения `isReady`
- При миграции старых данных — должны устанавливаться значения по умолчанию

### Если проблема в отображении

Проверьте функцию `isSectionReady`:

```typescript
const isSectionReady = (sectionState: SectionState | undefined): boolean => {
  if (!sectionState) return false;
  return sectionState.isReady;
};
```

**Проверьте:**
- Функция должна возвращать `sectionState.isReady`
- Индикаторы должны отображаться правильно:
  - Зелёная галочка (✓) для `isReady === true`
  - Красный крестик (✗) для `isReady === false`
