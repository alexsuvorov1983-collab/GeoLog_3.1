# Исправление экспорта DXF файлов

## Проблема
При нажатии кнопки "Экспорт в AutoCAD" файл DXF не создавался и не скачивался.

## Причина
В функции `downloadDXF` в файле `src/utils/dxfGenerator.ts` было неправильное создание Blob из Uint8Array:

```typescript
// НЕПРАВИЛЬНО
const blob = new Blob([encoded.buffer as ArrayBuffer], { type: 'application/dxf' });
```

Проблема в том, что `Uint8Array.buffer` возвращает `ArrayBuffer | SharedArrayBuffer`, а TypeScript не принимает это как `BlobPart` напрямую.

## Решение

### 1. Исправление создания Blob

```typescript
// ПРАВИЛЬНО
const arrayBuffer = encoded.buffer.slice(
  encoded.byteOffset, 
  encoded.byteOffset + encoded.byteLength
) as ArrayBuffer;
const blob = new Blob([arrayBuffer as unknown as BlobPart], { type: 'application/dxf' });
```

Ключевые изменения:
- Используем `slice()` для создания копии ArrayBuffer с правильными границами
- Применяем двойное приведение типов `as unknown as BlobPart` для обхода проверки TypeScript
- Добавлена обработка ошибок с try-catch

## Возможные проблемы и решения

### Проблема 1: Файл не скачивается
**Симптом:** В консоли есть все сообщения, но файл не появляется в загрузках

**Решение:**
- Проверьте настройки браузера для скачивания файлов
- Убедитесь, что не заблокированы popup
- Попробуйте другой браузер

### Проблема 2: Файл скачивается, но AutoCAD не может его открыть
**Симптом:** Файл есть, но AutoCAD показывает ошибку

**Решение:**
- Проверьте кодировку файла (должна быть CP1251)
- Убедитесь, что все секции DXF на месте
- Проверьте формат чисел (должны быть с точкой, не запятой)

### Проблема 3: Файл открывается, но графики не видны
**Симптом:** AutoCAD открывает файл, но экран пустой

**Решение:**
- Выполните команду `ZE` (Zoom Extents)
- Проверьте слой "ИИ_Термометрия" (должен быть включён)
- Проверьте координаты графики (должны быть в пределах $EXTMIN/$EXTMAX)

### Проблема 4: Кириллица отображается как вопросительные знаки
**Симптом:** Текст на русском языке не читается

**Решение:**
- Проверьте, что файл сохранён в кодировке CP1251
- Убедитесь, что в AutoCAD используется правильный шрифт
- Проверьте системную кодировку Windows
