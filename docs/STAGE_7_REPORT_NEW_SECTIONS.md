## Новые разделы

### 1. Обложка (report-cover)
Содержит информацию о:
- Названии организации
- Типе изысканий (инженерно-геологические)
- Названии объекта
- Шифре проекта
- Городе и годе выпуска

### 2. Титул (report-title)
Содержит информацию о:
- Министерстве строительства РФ
- Наименовании организации-исполнителя
- Заказчике и объекте
- Шифре проекта
- Руководителе изысканий
- Городе и годе выпуска

### 3. Список исполнителей (report-executors)
Содержит список:
- Руководитель изысканий
- Начальник отдела инженерных изысканий
- Главный специалист
- Инженер-геолог
- Техник
- Дата составления

### 4. Содержание тома (report-volume-contents)
Содержит перечень томов:
- Том I: Текстовая часть (Пояснительная записка)
- Том II: Графические материалы
- Том III: Приложения (таблицы, ведомости, паспорта)
- Том IV: Документы (техническое задание, программа работ, акты)

### 5. Состав отчётной документации (report-documentation)
Содержит перечень:
1. Пояснительная записка
2. Графические материалы (план, разрезы, колонки, таблицы)
3. Приложения (А-Я)
4. Документы (акты, таблицы регистрации)

### 6. Содержание (report-contents)
Содержит полный перечень разделов:
- Предварительные разделы (Обложка, Титул, Список исполнителей, Содержание тома, Состав отчётной документации, Содержание)
- Основные разделы (1-16)
- Приложения (А-Я)
- Таблица регистрации изменений

## Функциональность

### Автогенерация
При первом открытии окна "Пояснительная записка" все 6 новых разделов автоматически генерируются с шаблонным содержимым.

### Редактирование
Пользователь может:
- Нажать кнопку "✎ Редактировать" для редактирования текста
- Внести изменения в текстовое поле
- Нажать "✓ Сохранить" для сохранения изменений
- Нажать "✗ Отменить" для отмены изменений

### Отметка готовности
Пользователь может:
- Нажать кнопку "✗ Не готово" для отметки раздела как готового
- Кнопка меняется на "✓ Готово" (зелёная)
- Индикатор в навигации меняется на зелёную галочку (✓)
- Повторное нажатие возвращает раздел в состояние "не готов"

### Сохранение состояния
Все изменения сохраняются в localStorage:
- Ключ: `geolog_report_sections`
- Сохраняется текст каждого раздела
- Сохраняется состояние готовности (isReady)
- Сохраняется состояние редактирования (isEdited, isSaved)

## Структура данных

### Интерфейс ReportSection
```typescript
interface ReportSection {
  id: string;              // Уникальный идентификатор раздела
  number: string;          // Номер раздела (пустая строка для предварительных)
  title: string;           // Название раздела
  level: number;           // Уровень вложенности (1 = основной, 2 = подраздел)
  parentId?: string;       // ID родительского раздела (для подразделов)
  hasTable?: boolean;      // Наличие таблицы
  tableHeaders?: string[]; // Заголовки таблицы
}
```

### Интерфейс SectionState
```typescript
interface SectionState {
  id: string;              // ID раздела
  text?: string;           // Текст раздела
  tableRows?: string[][];  // Строки таблицы
  isEdited: boolean;       // Раздел редактируется
  isSaved: boolean;        // Изменения сохранены
  isReady: boolean;        // Раздел готов
}
```
