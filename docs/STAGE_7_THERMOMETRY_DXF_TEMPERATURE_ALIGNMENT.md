# Этап 7: Термометрия - Выравнивание температуры по засечкам

## Дата
2026-01-29

## Описание изменения
Изменено вертикальное выравнивание текста значений температуры для точного соответствия высоте засечек глубины.

## Проблема
Ранее значения температуры отображались с вертикальным выравниванием по верхнему краю (av=2), что приводило к визуальному смещению текста относительно засечек глубины.

## Решение
Изменён параметр вертикального выравнивания с `av=2` (по верхнему краю) на `av=1` (по середине), чтобы текст температуры был строго на той же высоте, что и засечка глубины.

## Изменения в коде

### Файл: `src/utils/dxfGenerator.ts`

**Строка 76:**

**Было:**
```typescript
text(x0 + 4, vy, 2.5, fmtVal(p.t), 0, 2, 1);
```

**Стало:**
```typescript
text(x0 + 4, vy, 2.5, fmtVal(p.t), 0, 1, 1);
```

### Объяснение параметров функции `text()`

```typescript
text(x, y, h, s, ah, av, color)
```

- `x, y` - координаты точки вставки
- `h` - высота текста
- `s` - строка текста
- `ah` - горизонтальное выравнивание (72)
  - 0 = по левому краю
  - 1 = по центру
  - 2 = по правому краю
- `av` - вертикальное выравнивание (73)
  - 0 = по нижнему краю
  - 1 = по середине
  - 2 = по верхнему краю
- `color` - цвет (62)
