# Этап 7: Пояснительная записка - Все разделы не готовы по умолчанию

## Дата
2026-01-29

## Описание изменения
Изменена логика инициализации готовности разделов: теперь **все разделы по умолчанию не готовы** (красная галочка ✗), кнопка отображается как "✗ Не готово" (красная).

## Изменения

### Инициализация новых разделов
**Было:**
```typescript
const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
return {
  id: section.id,
  text: content.text,
  tableRows: content.tableRows,
  isEdited: false,
  isSaved: true,
  isReady: isReadyByDefault  // Разделы 14 и 16 готовы
};
```

**Стало:**
```typescript
return {
  id: section.id,
  text: content.text,
  tableRows: content.tableRows,
  isEdited: false,
  isSaved: true,
  isReady: false  // Все разделы не готовы
};
```

### Миграция старых данных
**Было:**
```typescript
const migrated = parsed.map((section: any) => {
  const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
  return { ...section, isReady: isReadyByDefault };
});
```

**Стало:**
```typescript
const migrated = parsed.map((section: any) => {
  return { ...section, isReady: false };  // Все разделы не готовы
});
```

## Визуальное оформление

### По умолчанию (все разделы):
- **Индикатор:** красный крестик (✗)
- **Кнопка:** красная "✗ Не готово"
- **Tooltip:** "Раздел не готов"

### После нажатия кнопки:
- **Индикатор:** зелёная галочка (✓)
- **Кнопка:** зелёная "✓ Готово"
- **Tooltip:** "Раздел готов"

## Преимущества

1. **Единый подход:** все разделы начинаются с одинакового состояния (не готовы)
2. **Осознанный выбор:** пользователь должен явно отметить каждый готовый раздел
3. **Прозрачность:** легко видеть, какие разделы ещё не проверены
4. **Контроль качества:** пользователь подтверждает готовность каждого раздела
