# Экспорт термометрии в AutoCAD и Excel

## Обзор

Реализованы функции экспорта данных термометрии в форматы AutoCAD (DXF) и Excel (XLSX).

## Реализованные функции

### 1. Экспорт в AutoCAD (DXF)

**Файл:** `src/utils/thermoExport.ts` - функция `exportToDXF()`

**Возможности:**
- Генерация DXF файла формата AutoCAD R12 ASCII
- Создание слоя "Thermometry" для всех объектов
- Для каждой выбранной скважины рисуется:
  - Вертикальная ось глубин
  - Горизонтальная ось температур
  - Ломаная линия по точкам замеров
  - Заголовок с номером скважины
  - Подписи дат сессий
- Автоматическое масштабирование по глубине и температуре
- Графики располагаются горизонтально с интервалом 150 единиц

**Параметры:**
- `boreholes` - массив всех скважин
- `sessions` - массив всех сессий термометрии
- `selectedBoreholeIds` - опциональный массив ID выбранных скважин (если не указан, экспортируются все)

**Формат файла:**
- Имя файла: `Thermometry_YYYY-MM-DD.dxf`
- Формат: DXF R12 ASCII (совместим с AutoCAD 2000 и новее)

### 2. Экспорт в Excel (XLSX)

**Файл:** `src/utils/thermoExport.ts` - функция `exportToExcel()`

**Возможности:**
- Создание таблицы Excel с данными термометрии
- Структура таблицы:
  - Строка 1: Заголовки (Скважина, Дата, глубины)
  - Строки 2+: Данные по сессиям
- Автоматическое определение всех уникальных глубин
- Сортировка глубин по возрастанию
- Пустые ячейки для отсутствующих замеров
- Автоматическая настройка ширины колонок

**Параметры:**
- `boreholes` - массив всех скважин
- `sessions` - массив всех сессий термометрии
- `selectedBoreholeIds` - опциональный массив ID выбранных скважин (если не указан, экспортируются все)

**Формат файла:**
- Имя файла: `Thermometry_YYYY-MM-DD.xlsx`
- Формат: Microsoft Excel (XLSX)
- Лист: "Термометрия"

## Логика фильтрации

Обе функции экспорта поддерживают фильтрацию по выбранным скважинам:

- Если в селекторе выбрана конкретная скважина → экспортируются только сессии этой скважины
- Если выбрано "Все скважины" → экспортируются все сессии всех скважин

## Технические детали

### DXF формат

Структура DXF файла:
1. **HEADER** - версия AutoCAD (AC1009 = R12)
2. **TABLES** - определение слоя "Thermometry"
3. **BLOCKS** - пустая секция
4. **ENTITIES** - графические объекты:
   - TEXT - заголовки скважин и даты
   - LINE - оси координат и ломаные линии графиков
5. **EOF** - конец файла

Координаты:
- X: горизонтальная ось (температура)
- Y: вертикальная ось (глубина, инвертированная)
- Масштабирование: автоматическое по диапазону данных

### Excel формат

Структура таблицы:
```
| Скважина | Дата       | 0.5 м | 1.0 м | 1.5 м | ... |
|----------|------------|-------|-------|-------|-----|
| С-1      | 2024-03-15 | 7.8   | 8.0   | 8.1   | ... |
| С-1      | 2024-07-20 | 12.5  | 12.3  | 12.1  | ... |
| С-2      | 2024-03-16 | 7.5   | 7.8   | -     | ... |
```

Ширина колонок:
- Скважина: 15 символов
- Дата: 12 символов
- Глубины: 10 символов каждая

## Тестирование

### Тест экспорта в DXF:
1. Открыть вкладку "Термометрия"
2. Выбрать скважину с сессиями (например, С-1)
3. Нажать кнопку "📐 Экспорт в Автокад"
4. Проверить скачивание файла `Thermometry_YYYY-MM-DD.dxf`
5. Открыть файл в AutoCAD или другом DXF-просмотрщике
6. Проверить наличие графиков термометрии

### Тест экспорта в Excel:
1. Открыть вкладку "Термометрия"
2. Выбрать "Все скважины" или конкретную скважину
3. Нажать кнопку "📊 Экспорт в Эксель"
4. Проверить скачивание файла `Thermometry_YYYY-MM-DD.xlsx`
5. Открыть файл в Excel или LibreOffice Calc
6. Проверить структуру таблицы и данные

### Тест фильтрации:
1. Выбрать конкретную скважину в селекторе
2. Экспортировать в DXF и Excel
3. Проверить, что в файлах только данные выбранной скважины
4. Выбрать "Все скважины"
5. Экспортировать снова
6. Проверить, что в файлах данные всех скважин
