# Этап 7: Пояснительная записка - Финальное исправление инициализации готовности

## Дата
2026-01-29

## Описание проблемы
Пользователь сообщал, что по умолчанию готовы только разделы 14 и 16, но индикаторы готовности отображались неправильно. Проблема была связана с миграцией данных из localStorage.

## Корень проблемы
При загрузке данных из localStorage, если поле `isReady` уже присутствовало в старых данных (из предыдущих версий с другой логикой), миграция не выполнялась, и некорректные значения `isReady` сохранялись.

## Решение
Добавлена проверка необходимости миграции:
1. Если данные загружаются из localStorage и у первого раздела отсутствует поле `isReady` — выполняется миграция
2. При миграции для всех разделов устанавливается `isReady` по умолчанию (true только для 14 и 16)
3. Если поле `isReady` уже есть — данные считаются актуальными и миграция не выполняется
4. При первой загрузке (нет данных в localStorage) — инициализация с правильными значениями по умолчанию

## Логика миграции

```typescript
const [sections, setSections] = useState<SectionState[]>(() => {
  const saved = localStorage.getItem(SECTIONS_STORAGE_KEY);
  if (saved) {
    const parsed = JSON.parse(saved);
    
    // Проверяем, нужна ли миграция (если у первого раздела нет поля isReady)
    const needsMigration = parsed.length > 0 && parsed[0].isReady === undefined;
    
    if (needsMigration) {
      // Миграция: установить isReady по умолчанию
      const migrated = parsed.map((section: any) => {
        const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
        return { ...section, isReady: isReadyByDefault };
      });
      return migrated;
    } else {
      // Данные актуальны, миграция не требуется
      return parsed;
    }
  }
  
  // Инициализация новых разделов
  return REPORT_SECTIONS.map(section => {
    const content = generateSectionContent(section.id);
    const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
    return {
      id: section.id,
      text: content.text,
      tableRows: content.tableRows,
      isEdited: false,
      isSaved: true,
      isReady: isReadyByDefault
    };
  });
});
```
