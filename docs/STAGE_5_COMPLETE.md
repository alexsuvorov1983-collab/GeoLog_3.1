# Этап 5: Лабораторные опыты (часть 1)

## Обзор

Реализована система лабораторных опытов для детального анализа проб грунта. Каждый опыт представлен как отдельная карточка с таблицей замеров, автоматическим расчётом результатов и интеграцией с основной таблицей проб.

## Реализованные компоненты

### 1. Компрессионные испытания (`CompressionTest.tsx`)

**Назначение:** Определение деформационных характеристик грунта при сжатии.

**Функциональность:**
- Таблица замеров (давление, высота образца, абсолютная деформация)
- Автоматический расчёт:
  - Начальный коэффициент пористости e₀
  - Коэффициент сжимаемости m₀ (МПа⁻¹)
  - Модуль деформации Eoed (МПа)
- Ручной ввод высоты образца после опыта
- Настройка площади кольца и начальной высоты

**Формулы:**
```
m₀ = |Δh/h₀| / ΔP
Eoed = (1 + e₀) / m₀
```

### 2. Одноплоскостной срез (`ShearTest.tsx`)

**Назначение:** Определение прочностных характеристик грунта (сцепление и угол внутреннего трения).

**Функциональность:**
- Таблица пар «нормальное напряжение – касательное напряжение»
- Выбор состояния образца:
  - Естественное состояние
  - Водонасыщенное состояние
  - Мёрзлое состояние
- Автоматический расчёт методом линейной регрессии:
  - Сцепление c (кПа)
  - Угол внутреннего трения φ (град)
  - Коэффициент корреляции

**Формулы:**
```
τ = c + σ·tg(φ)
c = (Σy·Σx² - Σx·Σxy) / (n·Σx² - (Σx)²)
tg(φ) = (n·Σxy - Σx·Σy) / (n·Σx² - (Σx)²)
```

### 3. Гранулометрический состав (`GranulometryTest.tsx`)

**Назначение:** Определение гранулометрического состава грунта по ГОСТ 12536-2014.

**Функциональность:**
- Таблица замеров по 14 стандартным фракциям
- Кнопка быстрого добавления всех фракций
- Настройка общего веса пробы
- Опция мокрого рассева
- Автоматический расчёт:
  - Процентное содержание каждой фракции
  - Сумма частиц (контроль = 100%)
  - Заполнитель (<2 мм)
  - Содержание песка в мелкоземе

**Стандартные фракции:**
>200, 200-100, 100-60, 60-10, 10-5, 5-2, 2-1, 1-0.5, 0.5-0.25, 0.25-0.1, 0.1-0.05, 0.05-0.01, 0.01-0.005, <0.005 мм

### 4. Влажность и плотность (`MoistureDensityTest.tsx`)

**Назначение:** Определение влажности и плотности грунта.

**Функциональность:**
- Таблица замеров (вес образца, вес после высушивания)
- Выбор типа фракции:
  - Общая проба
  - Мелкие частицы (<2 мм)
  - Крупные частицы (>2 мм)
- Автоматический расчёт влажности для каждого замера
- Опция авторасчёта плотности
- Автоматический расчёт:
  - Средняя влажность (%)
  - Плотность грунта (г/см³)
  - Плотность сухого грунта (г/см³)

**Формулы:**
```
W = ((m - md) / md) × 100%
ρd = ρ / (1 + W/100)
```

### Обновлённый интерфейс `SoilTest`

```typescript
// Компрессионные испытания
interface CompressionTestData {
  initial_height_mm: number;
  ring_area_cm2: number;
  initial_moisture?: number;
  initial_density?: number;
  measurements: CompressionMeasurement[];
  final_height_mm?: number;
}

interface CompressionTestResults {
  e0?: number;
  m0?: number;
  Eoed?: number;
  Eoed_sat?: number;
  compression_coeff?: number;
}

// Одноплоскостной срез
interface ShearTestData {
  condition: 'natural' | 'saturated' | 'frozen';
  measurements: ShearMeasurement[];
  test_type?: 'plane' | 'triaxial' | 'frozen_surface';
}

interface ShearTestResults {
  c?: number;
  phi?: number;
  correlation?: number;
}

// Гранулометрический состав
interface GranulometryTestData {
  total_weight_g: number;
  measurements: GranulometryMeasurement[];
  wet_screening?: boolean;
  fraction_0002?: number;
}

interface GranulometryTestResults {
  particle_sum?: number;
  filler?: number;
  sand_in_fine?: number;
  fractions: Record<string, number>;
}

// Влажность и плотность
interface MoistureDensityTestData {
  fraction_type: 'fine' | 'coarse' | 'total';
  measurements: MoistureMeasurement[];
  calculate_density?: boolean;
}

interface MoistureDensityTestResults {
  average_moisture?: number;
  density?: number;
  dry_density?: number;
}
```

## Интеграция с таблицей проб

### Добавленные элементы

1. **Колонка "Опыты"** в таблице проб с кнопками:
   - **К** (синяя) — Компрессионные испытания
   - **С** (зелёная) — Одноплоскостной срез
   - **Г** (фиолетовая) — Гранулометрический состав
   - **В** (оранжевая) — Влажность и плотность

2. **Модальные окна** для каждого типа опыта:
   - Полноэкранные модальные окна (90% ширины и высоты экрана)
   - Закрытие по клику на фон или кнопку "Закрыть"
   - Автоматическое сохранение данных при изменении

3. **Автоматическое создание опытов:**
   - При первом клике на кнопку создаётся новый опыт
   - При повторном клике открывается существующий опыт для этой пробы
