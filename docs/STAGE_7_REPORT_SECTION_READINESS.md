# Индикаторы готовности разделов в пояснительной записке

## Дата
2026-01-29

## Описание изменения
Добавлены визуальные индикаторы готовности разделов в модуле "Пояснительная записка". Теперь каждый раздел помечается зелёной галочкой (✓) если он готов, или красным крестиком (✗) если раздел не готов.

## Критерии готовности раздела

Раздел считается **готовым**, если выполнено хотя бы одно условие:
- Есть непустой текст (после удаления пробелов)
- Есть таблица с хотя бы одной строкой данных

Раздел считается **не готовым**, если:
- Текст отсутствует или пустой
- Таблица отсутствует или не содержит строк данных

## Реализация

### Функция проверки готовности

Добавлена функция `isSectionReady()` в `src/components/ReportWindow.tsx`:

```typescript
const isSectionReady = (sectionState: SectionState | undefined): boolean => {
  if (!sectionState) return false;
  
  // Раздел готов, если есть непустой текст ИЛИ есть таблица с данными
  const hasText = Boolean(sectionState.text && sectionState.text.trim().length > 0);
  const hasTable = Boolean(sectionState.tableRows && sectionState.tableRows.length > 0);
  
  return hasText || hasTable;
};
```

### Отображение в левой панели навигации

В левой панели навигации индикатор готовности отображается перед названием раздела:

```tsx
<span className={`text-lg ${isReady ? 'text-green-600' : 'text-red-500'}`}>
  {isReady ? '✓' : '✗'}
</span>
```

**Пример отображения:**
```
✓ 1. Введение
✓ 2. Изученность инженерно-геологических условий
✗ 3. Физико-географические и technoгенные условия
✓ 4. Методики и технология выполнения работ
```

### Отображение в правой панели (заголовки разделов)

В правой панели индикатор готовности отображается перед заголовком раздела:

```tsx
<div className="flex items-center gap-3">
  <span className={`text-2xl ${isReady ? 'text-green-600' : 'text-red-500'}`} 
        title={isReady ? 'Раздел готов' : 'Раздел не готов'}>
    {isReady ? '✓' : '✗'}
  </span>
  <h2 className={`font-bold text-gray-800 ${section.level === 1 ? 'text-2xl' : 'text-xl pl-4'}`}>
    {section.number && <span>{section.number} </span>}
    {section.title}
  </h2>
</div>
```

## Визуальное оформление

### Цвета индикаторов
- **Зелёная галочка (✓)**: `text-green-600` — раздел готов
- **Красный крестик (✗)**: `text-red-500` — раздел не готов

### Размеры
- В левой панели: `text-lg` (большой размер)
- В правой панели: `text-2xl` (очень большой размер)

### Tooltip
В правой панели при наведении на индикатор отображается подсказка:
- "Раздел готов" — для зелёной галочки
- "Раздел не готов" — для красного крестика

## Автоматическое обновление

Индикаторы готовности обновляются автоматически:
1. **При автогенерации** — когда раздел генерируется из данных проекта
2. **При редактировании** — когда пользователь вводит текст или заполняет таблицу
3. **При сохранении** — когда изменения сохраняются в localStorage
4. **При загрузке** — когда документ загружается из localStorage

## Примеры использования

```
✓ 4. Методики и технология выполнения работ

Раздел готов, так как содержит автогенерированный текст с данными о скважинах и пробах.

```

Раздел не готов, так как текст пустой и таблица отсутствует.

```

```
Раздел готов, так как содержит таблицу с данными из каталога ИГЭ.

### Пример 4: Раздел в процессе редактирования
```
● ✓ 1. Введение
```
Раздел готов (зелёная галочка), но есть несохранённые изменения (красная точка).
