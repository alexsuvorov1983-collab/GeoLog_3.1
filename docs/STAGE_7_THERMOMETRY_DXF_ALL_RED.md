# Этап 7: Термометрия - Все данные красным цветом

## Дата
2026-01-29

## Описание изменения
Все элементы графика термометрии теперь отображаются красным цветом (color=1) в AutoCAD.

## Проблема
Ранее ось глубин и подписи глубин были черными (color=7), а остальные элементы - красными (color=1). Это создавало визуальное разделение, но пользователь запросил единый красный цвет для всех данных.

## Решение
Изменен цвет оси глубин и подписей глубины с черного (color=7) на красный (color=1).

## Изменения в коде

### Файл: `src/utils/dxfGenerator.ts`

**Строка 68:**

**Было:**
```typescript
line(x0, yTop, x0, yTop - H);
```

**Стало:**
```typescript
line(x0, yTop, x0, yTop - H, 1);
```

**Строка 73:**

**Было:**
```typescript
text(x0 - 3, y, 2.5, p.depth.toFixed(1), 2, 1);
```

**Стало:**
```typescript
text(x0 - 3, y, 2.5, p.depth.toFixed(1), 2, 1, 1);
```

## Результат

Теперь все элементы графика термометрии отображаются красным цветом:

```
    С-1                    ← красный
  15.03.2024               ← красный
    |                      ← красный (ось)
  0.0 ←|→→|  10.00        ← все красное
    |
  2.5 ←|→→|   8.50        ← все красное
    |
  5.0 ←|→→|  12.50        ← все красное
    |
  7.5 ←|→→|  15.00        ← все красное
    |
 10.0 ←|→→|  18.00        ← все красное
    |
  0.0                      ← красный (подпись глубины)
```

## Структура графика

```
|← 3 мм →|← 2 мм →|← 3 мм →|
         |
    Подписи   Ось    Засечки  Значения
    глубин    глубин  глубины  температур
   (x0-3)    (x0)   (x0-2→x0) (x0→x0+2) (x0+3)
   красные   красная  красные   красные    красные
```

**Все элементы теперь красные (color=1):**
- Ось глубин (вертикальная линия)
- Засечки слева и справа
- Подписи глубин
- Значения температуры
- Шапка (номер скважины и дата)

## Преимущества

1. **Единый стиль**
   - Все данные выделены одним цветом
   - Визуальная целостность графика
   - Легко отличить данные термометрии от других элементов чертежа

2. **Улучшенная видимость**
   - Красный цвет хорошо заметен на белом фоне
   - Данные легко читаются при печати
   - Выделение термометрии на общем плане

3. **Соответствие запросу**
   - Выполнено требование пользователя
   - Все данные термометрии в едином стиле
