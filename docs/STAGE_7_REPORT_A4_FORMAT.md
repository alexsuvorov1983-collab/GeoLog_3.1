# Этап 7: Пояснительная записка - Форматирование в стиле A4

## Дата
2026-01-29

## Описание изменения
Изменено отображение содержимого пояснительной записки для имитации формата листов A4:
- Каждый раздел отображается на отдельном листе A4
- Шрифт Times New Roman 12pt
- Наименования разделов отображаются ЗАГЛАВНЫМИ БУКВАМИ
- Поля страницы: левое 30мм, правое 15мм, верхнее/нижнее 20мм

## Изменения в ReportWindow.tsx

### 1. Контейнер листа A4
Добавлен новый div-контейнер для каждого раздела с форматированием A4:

```tsx
<div 
  className="bg-white shadow-lg mx-auto"
  style={{
    width: '210mm',
    minHeight: '297mm',
    padding: '20mm 15mm 20mm 30mm',
    fontFamily: '"Times New Roman", Times, serif',
    fontSize: '12pt',
    lineHeight: '1.5',
    pageBreakBefore: 'always'
  }}
>
```

**Параметры:**
- `width: '210mm'` - ширина листа A4
- `minHeight: '297mm'` - минимальная высота листа A4
- `padding: '20mm 15mm 20mm 30mm'` - поля страницы (верх, право, низ, лево)
- `fontFamily: '"Times New Roman", Times, serif'` - шрифт Times New Roman
- `fontSize: '12pt'` - размер шрифта 12 пунктов
- `lineHeight: '1.5'` - межстрочный интервал 1.5
- `pageBreakBefore: 'always'` - разрыв страницы перед каждым разделом

### 2. Заголовки разделов ЗАГЛАВНЫМИ БУКВАМИ
Изменён рендеринг заголовков разделов:

```tsx
<h2 className={`font-bold text-gray-800 uppercase ${section.level === 1 ? 'text-2xl' : 'text-xl pl-4'}`}>
  {section.number && <span>{section.number} </span>}
  {section.title.toUpperCase()}
</h2>
```

**Изменения:**
- Добавлен класс `uppercase` для автоматического преобразования в верхний регистр
- Добавлен вызов `.toUpperCase()` для заголовка раздела

### 3. Фон правой панели
Изменён фон правой панели для лучшего визуального разделения:

```tsx
<div ref={contentRef} className="flex-1 overflow-y-auto p-6 bg-gray-100">
```

Добавлен класс `bg-gray-100` для серого фона, чтобы белые листы A4 выделялись.

## Преимущества

1. **Визуальное соответствие** - документ выглядит как настоящая пояснительная записка
2. **Удобство редактирования** - пользователь видит, как будет выглядеть документ при печати
3. **Стандартизация** - единый шрифт и форматирование для всех разделов
4. **Профессиональный вид** - ЗАГЛАВНЫЕ БУКВЫ в заголовках соответствуют стандартам
5. **Готовность к печати** - можно сразу печатать без дополнительной форматирования

## Технические детали

### Формат A4
- Ширина: 210 мм (8.27 дюймов)
- Высота: 297 мм (11.69 дюймов)
- Соотношение сторон: 1:√2

### Поля страницы
- Левое: 30 мм (для переплёта)
- Правое: 15 мм
- Верхнее: 20 мм
- Нижнее: 20 мм

### Шрифт
- Семейство: Times New Roman
- Размер: 12 пунктов (16 пикселей при 96 DPI)
- Межстрочный интервал: 1.5

### Разрыв страницы
- CSS свойство: `page-break-before: always`
- Гарантирует начало каждого раздела с нового листа при печати

## Совместимость с экспортом в DOCX
