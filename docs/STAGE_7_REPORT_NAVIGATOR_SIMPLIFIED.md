## Преимущества

### 1. Упрощение навигатора
- Навигатор стал более компактным
- Меньше визуального шума
- Легче ориентироваться в других разделах

### 2. Логичная структура
- Разделы и приложения ПЗ управляются внутри окна ПЗ
- Навигатор используется только для открытия окна ПЗ
- Нет дублирования информации

### 3. Улучшение UX
- Клик по "ПОЯСНИТЕЛЬНАЯ ЗАПИСКА" сразу открывает окно
- Не нужно раскрывать дерево для навигации по разделам
- Навигация по разделам происходит внутри окна ПЗ через левую панель

### 4. Соответствие архитектуре
- Окно ПЗ имеет собственную навигацию (левая панель)
- Навигатор проекта используется для открытия основных окон
- Разделение ответственности между компонентами

## Как работает навигация по разделам ПЗ

### Открытие окна ПЗ
1. Клик по "📝 ПОЯСНИТЕЛЬНАЯ ЗАПИСКА" в навигаторе
2. Открывается плавающее окно ПЗ

### Навигация внутри окна ПЗ
1. В левой панели окна ПЗ отображается полный список разделов
2. Клик по разделу прокручивает к нему в правой панели
3. Scrollspy подсвечивает текущий раздел в левой панели
4. Можно сворачивать/разворачивать левую панель

### Управление разделами
1. Каждый раздел имеет кнопки:
   - ✎ Редактировать
   - ↺ Автогенерация
   - ✓ Готово / ✗ Не готово
   - 📷 Загрузить (для приложений)
2. Индикаторы готовности показывают статус каждого раздела
3. Все изменения сохраняются в localStorage
