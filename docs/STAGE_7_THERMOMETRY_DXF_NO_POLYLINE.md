# Этап 7: Термометрия - Удаление температурной кривой из DXF

## Обзор

Убрана температурная кривая (POLYLINE) из экспорта DXF. Теперь в AutoCAD отображаются только табличные графики с засечками, подписями глубин и температур, без соединительной линии между точками замеров.

## Изменения

### Удаление полилинии

**Файл:** `src/utils/dxfGenerator.ts` (строки 73-74)

**Было:**
```typescript
const pl: Array<[number, number]> = pts.map(p => [x0 + p.t * MM_PER_C, yTop - p.depth * mmPerM]);
poly(pl);
```

**Стало:**
```typescript
// Полилиния удалена - только табличные подписи
```

**Описание:**
- Удалено формирование массива точек для температурной кривой
- Удалён вызов функции `poly(pl)` для построения POLYLINE примитива
- Оставлены все остальные элементы графика:
  - Вертикальная ось глубин
  - Засечки на оси глубин
  - Подписи глубин (слева от оси)
  - Подписи температур (справа от оси)
  - Заголовок с номером скважины и датой

## Преимущества

1. **Упрощение визуализации**
   - Убрана лишняя линия, которая могла перекрывать подписи
   - Более чистый и читаемый график
   - Акцент на числовых значениях

2. **Уменьшение размера файла**
   - Не генерируются POLYLINE, VERTEX, SEQEND примитивы
   - Файл DXF становится меньше
   - Быстрее открывается в AutoCAD

3. **Соответствие табличному формату**
   - График теперь полностью табличный
   - Все данные представлены в виде чисел
   - Легче считывать точные значения

4. **Улучшенная читаемость**
   - Подписи температур не перекрываются полилинией
   - Нет визуального шума
   - Профессиональное оформление

## Функция poly()

Функция `poly()` осталась в коде, но больше не вызывается:

```typescript
const poly = (pts: Array<[number, number]>) => {
  if (pts.length < 2) { return; }
  push(0, 'POLYLINE'); push(8, LAYER); push(62, 7); push(66, 1); push(70, 0);
  for (const pt of pts) { push(0, 'VERTEX'); push(8, LAYER); push(10, pt[0].toFixed(2)); push(20, pt[1].toFixed(2)); push(30, '0.00'); }
  push(0, 'SEQEND'); push(8, LAYER);
};
```

**Примечание:** Функция не удалена, так как может понадобиться в будущем для других типов графиков.
