## Реализованные компоненты

### 1. Модуль системы проверок (ValidationSystem.ts)

**Назначение:** Автоматическая валидация данных проб грунта в реальном времени.

**Типы проверок:**

#### 1.1. Проверка суммы фракций
- Контроль суммы гранулометрического состава = 100%
- Настраиваемый допуск (по умолчанию ±1%)
- Подсветка красным при превышении допуска

**Формула:**
```
Δ = |Σ фракций - 100%|
Если Δ > tolerance → ошибка
```

#### 1.2. Проверка дублирования номеров
- Контроль уникальности полевых номеров
- Контроль уникальности лабораторных номеров
- Предупреждение при обнаружении дубликатов

#### 1.3. Проверка диапазонов значений
- Влажность W: 0-100%
- Плотность ρ: 1.0-3.0 г/см³
- Плотность частиц ρs: 2.0-3.0 г/см³
- Угол внутреннего трения φ: 0-90°
- Ошибка при выходе за допустимые границы

#### 1.4. Проверка расчётных показателей
- Число пластичности Ip ≥ 0
- Показатель текучести IL: предупреждение при выходе за пределы -0.5...2.0
- Коэффициент водонасыщения Sr: предупреждение при выходе за пределы 0...1.5

#### 1.5. Проверка наличия ИГЭ
- Информационное сообщение для проб без привязки к ИГЭ

**Интерфейс ValidationSettings:**
```typescript
interface ValidationSettings {
  particleSumTolerance: number; // Допуск для суммы фракций, %
  fillerThreshold: number; // Нижний порог для выделения заполнителя, %
  excludeCoarseFromDispersed: boolean; // Исключать фракции >2 мм
  precision: Record<string, number>; // Точность для каждой колонки
}
```

**Интерфейс ValidationError:**
```typescript
interface ValidationError {
  type: 'error' | 'warning' | 'info';
  sampleId: string;
  field: string;
  message: string;
  value?: any;
}
```

### 2. Компонент статистики по ИГЭ (IgeStatistics.tsx)

**Назначение:** Отображение полной статистики по каждому ИГЭ согласно ГОСТ 20522.

**Функциональность:**

#### 2.1. Группировка проб по ИГЭ
- Автоматическая группировка всех проб по коду ИГЭ
- Отображение количества проб для каждого ИГЭ
- Кнопки быстрого выбора ИГЭ

#### 2.2. Расчёт статистических показателей

Для каждого параметра рассчитывается:
- **n** — число определений
- **min** — минимальное значение
- **max** — максимальное значение
- **X̄ (среднее)** — нормативное значение
- **σ** — стандартное отклонение
- **V** — коэффициент вариации (V = σ / X̄)
- **Расчётные значения** при α = 0.85, 0.90, 0.95, 0.98

**Формулы:**
```
Среднее: X̄ = Σxᵢ / n
Дисперсия: D = Σ(xᵢ - X̄)² / (n - 1)
Стандартное отклонение: σ = √D
Коэффициент вариации: V = σ / X̄
Коэффициент безопасности: k = 1 + V × (1 - α) × 2
Расчётное значение: X_r = X̄ / k
```

**Параметры для статистики:**
- W — Влажность, %
- WL — Влажность на границе текучести, %
- WP — Влажность на границе раскатывания, %
- ρ — Плотность, г/см³
- ρd — Плотность сухого грунта, г/см³
- ρs — Плотность частиц, г/см³
- c — Сцепление, кПа
- φ — Угол внутреннего трения, °
- Eoed — Модуль деформации, МПа
- Rc_dry — Прочность на сжатие всухую, МПа
- Rc_sat — Прочность на сжатие водонасыщенная, МПа
- RQD — Индекс качества керна, %

#### 2.3. Панель настроек валидации
- Настройка допуска для суммы фракций
- Настройка нижнего порога заполнителя
- Автоматическое применение настроек

#### 2.4. Сводка ошибок
- Подсчёт ошибок по типам (ошибки, предупреждения, информация)
- Цветовая индикация:
  - 🔴 Красный — критические ошибки
  - 🟡 Жёлтый — предупреждения
  - 🔵 Синий — информационные сообщения

#### 2.5. Список проблем

- Цветовая кодировка по типу проблемы
- Возможность прокрутки при большом количестве проблем

### Расчёт статистики

**Стандартное отклонение:**
```typescript
const variance = values.reduce((s, v) => s + Math.pow(v - mean, 2), 0) / (n - 1);
const stdDev = Math.sqrt(variance);
```

**Коэффициент вариации:**
```typescript
const variationCoeff = mean > 0 ? stdDev / mean : 0;
```

**Расчётные значения с коэффициентами безопасности:**
```typescript
const alphas = [0.85, 0.90, 0.95, 0.98];
alphas.forEach(alpha => {
  const safetyCoeff = 1 + variationCoeff * (1 - alpha) * 2;
  designValues[alpha.toString()] = normative / safetyCoeff;
});
```

### Валидация данных

**Проверка суммы фракций:**
```typescript
const diff = Math.abs(calculated.particleSum - 100);
if (diff > settings.particleSumTolerance) {
  errors.push({
    type: 'error',
    sampleId: sample.id,
    field: 'particle_sum',
    message: `Сумма фракций ${calculated.particleSum.toFixed(1)}% отличается от 100%`,
    value: calculated.particleSum
  });
}
```

**Проверка дублирования:**
```typescript
const fieldNumbers = new Map<string, Sample[]>();
samples.forEach(sample => {
  if (sample.field_number) {
    if (!fieldNumbers.has(sample.field_number)) {
      fieldNumbers.set(sample.field_number, []);
    }
    fieldNumbers.get(sample.field_number)!.push(sample);
  }
});

fieldNumbers.forEach((samplesWithNumber, number) => {
  if (samplesWithNumber.length > 1) {
    errors.push({
      type: 'warning',
      sampleId: sample.id,
      field: 'field_number',
      message: `Дублирование полевого номера "${number}"`
    });
  }
});
```
