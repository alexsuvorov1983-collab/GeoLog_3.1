# Этап 7: Термометрия - Импорт из Excel

## Обзор

Реализована функция импорта данных термометрии из Excel файлов (.xlsx/.xls) с предпросмотром и подтверждением.

## Возможности

### 1. Выбор и чтение файла
- Поддержка форматов .xlsx и .xls
- Автоматический поиск листа "Термометрия" или первого подходящего листа
- Ожидаемая структура:
  - Строка 1: Заголовки (Дата, № скважины, Глубина замера, м...)
  - Строка 2: Числовая сетка глубин (0.5, 1.0, 1.5, ...)
  - Строки 3+: Данные (дата, номер скважины, температуры)

### 2. Парсинг данных
- **Даты**: поддержка Excel serial number и строковых форматов (ДД.ММ.ГГГГ, ДД.ММ.ГГ, М/Д/ГГ)
- **Номера скважин**: автоматический поиск существующих или создание новых
- **Температуры**: чтение по колонкам глубин, пропуск пустых ячеек

### 3. Предпросмотр и подтверждение
- Статистика импорта:
  - Количество сессий для импорта
  - Общее количество замеров
  - Количество скважин, которые будут созданы
- Список предупреждений:
  - Некорректные даты
  - Отсутствующие номера скважин
  - Строки без данных о температурах
  - Скважины, которые будут созданы
- Кнопки "Импортировать" и "Отмена"

### 4. Запись в базу данных
- Создание отсутствующих скважин с provenance: import
- Создание новых сессий термометрии
- Обновление существующих сессий (по boreholeId + дата)
- Запись в журнал событий
- Автоматическое обновление интерфейса

### 5. Обработка ошибок
- Понятные сообщения об ошибках структуры файла
- Пропуск невалидных строк с предупреждениями
- Защита от дублирования данных при повторном импорте

## Реализация

### Компонент ThermoImportDialog

**Файл:** `src/components/ThermoImportDialog.tsx`

**Основные функции:**

1. **handleFileSelect** - чтение и парсинг Excel файла
   - Поиск целевого листа
   - Чтение сетки глубин
   - Разбор строк данных
   - Формирование предпросмотра

2. **handleImport** - запись данных в базу
   - Создание отсутствующих скважин
   - Создание/обновление сессий
   - Запись в журнал
   - Обновление интерфейса

3. **excelDateToISO** - конвертация Excel serial number в ISO дату
   - Формула: (serial - 25569) * 86400000 мс

4. **parseStringDate** - парсинг строковых дат
   - Поддержка форматов: ДД.ММ.ГГГГ, ДД.ММ.ГГ, М/Д/ГГ

## Пример использования

1. Открыть вкладку "Термометрия"
2. Нажать кнопку "📥 Импорт из Excel"
3. Выбрать файл .xlsx или .xls
4. Просмотреть предпросмотр импорта:
   - Количество сессий
   - Количество замеров
   - Количество создаваемых скважин
   - Список предупреждений
5. Нажать "✓ Импортировать" для подтверждения
6. Данные автоматически появятся в таблице

## Обработка ошибок

### Ошибка: не найден лист с данными
```
❌ Не найден лист с данными термометрии.

Ожидаемая структура:
• Строка 1: Заголовки (Дата, № скважины, Глубина замера, м)
• Строка 2: Числовая сетка глубин
• Строки 3+: Данные (дата, номер скважины, температуры)
```

### Ошибка: недостаточно данных
```
❌ Файл содержит недостаточно данных.

Ожидаемая структура:
• Строка 1: Заголовки
• Строка 2: Сетка глубин
• Строки 3+: Данные
```

### Ошибка: не найдена сетка глубин
```
❌ Не найдена сетка глубин во второй строке файла.
```

### Ошибка: нет валидных строк
```
❌ Не найдено ни одной валидной строки с данными термометрии.
```
