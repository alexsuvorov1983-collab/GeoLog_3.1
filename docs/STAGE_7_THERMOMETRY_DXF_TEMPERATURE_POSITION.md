# Этап 7: Термометрия - Перемещение подписей температур

## Обзор

Подписи температур перемещены справа от вертикальной оси глубин для улучшения читаемости и согласованности с подписями глубин.

## Изменения

### Позиционирование подписей температур

**Было:**
```typescript
for (const p of pts) {
  const vx = x0 + p.t * MM_PER_C;
  const vy = yTop - p.depth * mmPerM;
  text(vx + 1.5, vy, 2.5, fmtVal(p.t), 0, 2);
}
```
- Подписи размещались на 1.5 мм правее вершин температурной кривой
- Позиция зависела от значения температуры (vx = x0 + t × 2)
- Подписи "плавали" вместе с кривой

**Стало:**
```typescript
for (const p of pts) {
  const vy = yTop - p.depth * mmPerM;
  text(x0 + 2, vy, 2.5, fmtVal(p.t), 0, 2);
}
```
- Подписи размещаются на фиксированном расстоянии 2 мм справа от вертикальной оси глубин (x0)
- Позиция не зависит от значения температуры
- Все подписи выровнены по одной вертикали

### Обновление расчёта экстентов

**Было:**
```typescript
if (x0 + W + 5 > maxX) { maxX = x0 + W + 5; }
```
- Добавлялся запас 5 мм для подписей температур справа от кривой

**Стало:**
```typescript
if (x0 + W > maxX) { maxX = x0 + W; }
```
- Запас не нужен, так как подписи теперь внутри графика
- maxX = x0 + W (ширина графика 40 мм)

## Преимущества нового расположения

1. **Улучшенная читаемость**
   - Все подписи температур выровнены по одной вертикали
   - Легче сравнивать значения на разных глубинах
   - Нет визуального "шума" от плавающих подписей

2. **Согласованность с подписями глубин**
   - Подписи глубин: слева от оси (x0 - 3 мм)
   - Подписи температур: справа от оси (x0 + 2 мм)
   - Симметричное расположение относительно оси

3. **Компактность**
   - Подписи занимают меньше места по горизонтали
   - Не нужно увеличивать запас для экстентов
   - Более эффективное использование пространства

4. **Профессиональный вид**
   - Соответствует стандартам инженерных чертежей
   - Аналогично оформлению в эталонных инструментах
   - Улучшает восприятие данных

## Пример расчёта координат

**Входные данные:**
- x0 = 10 мм (позиция оси глубин)
- Глубина: 5.0 м
- Температура: 12.50 °C
- Масштаб: 1:100 (mmPerM = 10)
- yTop = 0 мм

**Расчёт:**
```
vy = 0 - 5.0 × 10 = -50.00 мм
Позиция текста: (10 + 2, -50.00) = (12.00, -50.00)
```

**Результат:**
- Текст " 12.50" размещён на 2 мм правее оси глубин
- На высоте -50.00 мм (соответствует глубине 5.0 м)
- Выровнен по левому нижнему углу

## Раскладка графика

```
|← 3 мм →|← 2 мм →|← до 40 мм →|
         |        |              |
    Подписи   Ось     Температурная
    глубин    глубин     кривая
   (x0-3)    (x0)    (x0 + t×2)
              |
         Подписи температур
           (x0+2)
```

**Горизонтальные позиции:**
- x0 - 3 мм: подписи глубин (справа от засечек)
- x0: вертикальная ось глубин
- x0 + 2 мм: подписи температур (справа от оси)
- x0 + t×2 мм: вершины температурной кривой

**Вертикальные позиции:**
- yTop - depth × mmPerM: высота для каждой глубины
- Засечки, подписи и вершины кривой на одной высоте
