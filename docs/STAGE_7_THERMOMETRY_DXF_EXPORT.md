# Экспорт термометрии в DXF (AutoCAD) по эталону thermo2cad.html

## Обзор

Реализован экспорт данных термометрии в формат DXF (AutoCAD R12) точно по логике эталонного файла `thermo2cad.html`. В отличие от предыдущей реализации, которая создавала ломаные линии температур, новая версия генерирует **табличные графики** с числовыми значениями (засечки + подписи глубин слева + температуры справа).

## Ключевые отличия от предыдущей версии

### Старая реализация (удалена)
- Генерировала ломаные линии (POLYLINE) по точкам замеров
- Простая визуализация без числовых значений
- Слой "Thermometry"

### Новая реализация (по эталону)
- Генерирует табличные графики с засечками и подписями
- Каждое значение температуры отображается текстом рядом с засечкой
- Глубины подписаны слева от оси
- Слой "ИИ_Термометрия" (точно как в эталоне)
- Кодировка CP1251 для корректного отображения кириллицы в AutoCAD

1. Фильтрует выбранные сессии
2. Пропускает сессии без данных (запись в журнал)

4. Генерирует DXF с выбранным масштабом
5. Формирует имя файла: `Thermometry_<N>скв_<scale>_<date>.dxf`
6. Скачивает файл
7. Записывает операцию в журнал

## Технические детали

### Кодировка CP1251

Функция `toCp1251` преобразует Unicode строку в массив байтов CP1251:

```typescript
function toCp1251(s: string): Uint8Array {
  const out: number[] = [];
  for (const ch of s) {
    const c = ch.codePointAt(0)!;
    let b: number;
    if (c < 0x80) b = c;
    else if (c >= 0x0410 && c <= 0x042F) b = 0xC0 + (c - 0x0410); // А-Я
    else if (c >= 0x0430 && c <= 0x044F) b = 0xE0 + (c - 0x0430); // а-я
    else if (c === 0x0401) b = 0xA8; // Ё
    else if (c === 0x0451) b = 0xB8; // ё
    else if (c === 0x2116) b = 0xB9; // №
    else if (c === 0x00B0) b = 0xB0; // °
    // ... другие символы
    else b = 0x3F; // ? для неизвестных
    out.push(b);
  }
  return new Uint8Array(out);
}
```

### Форматирование даты

Функция `formatDate` поддерживает три формата:

```typescript
export function formatDate(dateStr: string, mode: DateFormat): string {
  // Парсинг из ISO, ДД.ММ.ГГГГ, M/D/YY
  // ...
  
  if (mode === 'dmy4') return `${dd}.${mm}.${yyyy}`; // 03.07.2026
  if (mode === 'dmy2') return `${dd}.${mm}.${yy}`;   // 03.07.26
  return `${dateObj.getMonth() + 1}/${dateObj.getDate()}/${yy}`; // 7/3/26
}
```

### Генерация табличного графика

Функция `tableDXF` создаёт табличный график с засечками и подписями:

```typescript
function tableDXF(e: ThermoExportEntry, ox: number, oy: number, u: number): string {
  const TH = Math.min(2.5, 0.5 * u * 0.7); // Высота текста
  const k = TH / 2.5; // Коэффициент масштабирования
  
  let s = '';
  
  // Заголовок
  s += T(ox, oy, TTH, 'Результаты замеров термометрии', 7, 1, 2, ox);
  
  // Подзаголовок с номером скважины и датой
  s += T(cx - G, y2, TH, '№ скважины ', 7, 2, 2, cx - G);
  s += T(cx, y2, TH, `${e.name}  ${e.date}`, 1, 1, 2, cx);
  s += T(cx + G, y2, TH, 'Дата замера', 7, 0, 2, cx + G);
  
  // Заголовки колонок
  s += T(ox - 3 * k, yH, TH, 'Глубина замера, м', 7, 2, 2, ox - 3 * k);
  s += T(ox + 3 * k, yH, TH, 'Результаты замеров, °C', 7, 0, 2, ox + 3 * k);
  
  // Вертикальная ось
  s += L(ox, yOf(firstD) + 0.5 * u, ox, yOf(lastD), 1);
  
  // Засечки и подписи для каждого замера
  data.forEach(r => {
    const y = yOf(r.d);
    s += L(ox - 1.5 * k, y, ox + 1.5 * k, y, 1); // Засечка
    s += T(ox + 2 * k, y, TH, fmtVal(r.t!), 1, 0, 0, ox + 2 * k); // Температура
    s += T(ox - 2 * k, y, TH, r.d.toFixed(1), 1, 2, 0, ox - 2 * k); // Глубина
  });
  
  return s;
}
```

### Раскладка графиков

**Одиночный масштаб:**

```typescript
const COLS = 4;
const SLOT_W = 110;
const slots = Math.ceil(list.length / COLS);

list.forEach((e, i) => {
  ent += tableDXF(e, (i % COLS) * SLOT_W, slotY[Math.floor(i / COLS)], u);
});
```

**Режим "оба":**

```typescript
const GAP = 165;
const VGAP = 25;
let y = 0;

list.forEach(e => {
  const h100 = tableHeight(e, 10);
  const h5 = tableHeight(e, 5);
  ent += tableDXF(e, 0, y, 10);      // 1:100 слева
  ent += tableDXF(e, GAP, y, 5);     // 1:200 справа
  y -= (Math.max(h100, h5) + VGAP);  // Следующая ниже
});
```
