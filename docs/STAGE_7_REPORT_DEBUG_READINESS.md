# Этап 7: Пояснительная записка - Отладка инициализации готовности разделов

## Дата
2026-01-29

## Описание проблемы
Пользователь сообщал, что по умолчанию готовы только разделы 14 и 16, но индикаторы готовности отображались неправильно. Проблема была связана с миграцией данных из localStorage.

## Диагностика

### Добавлено логирование
В функцию инициализации состояния `sections` добавлены console.log для отладки:

```typescript
const [sections, setSections] = useState<SectionState[]>(() => {
  const saved = localStorage.getItem(SECTIONS_STORAGE_KEY);
  if (saved) {
    const parsed = JSON.parse(saved);
    console.log('[ReportWindow] Загружено из localStorage:', parsed.length, 'разделов');
    // Миграция: если поле isReady отсутствует, установить по умолчанию
    const migrated = parsed.map((section: any) => {
      if (section.isReady === undefined) {
        const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
        console.log(`[ReportWindow] Миграция раздела ${section.id}: isReady = ${isReadyByDefault}`);
        return { ...section, isReady: isReadyByDefault };
      }
      return section;
    });
    console.log('[ReportWindow] Готовые разделы:', migrated.filter((s: any) => s.isReady).map((s: any) => s.id));
    return migrated;
  }
  console.log('[ReportWindow] Инициализация новых разделов');
  // Инициализация разделов автогенерацией
  // По умолчанию готовы только разделы 14 и 16
  const initialized = REPORT_SECTIONS.map(section => {
    const content = generateSectionContent(section.id);
    const isReadyByDefault = section.id === 'report-14' || section.id === 'report-16';
    return {
      id: section.id,
      text: content.text,
      tableRows: content.tableRows,
      isEdited: false,
      isSaved: true,
      isReady: isReadyByDefault
    };
  });
  console.log('[ReportWindow] Готовые разделы по умолчанию:', initialized.filter(s => s.isReady).map(s => s.id));
  return initialized;
});
```

## Инструкция по тестированию

### Тест 1: Первая загрузка (чистый localStorage)

1. **Очистите localStorage:**
   - Откройте DevTools (F12)
   - Перейдите на вкладку Application (Chrome) или Storage (Firefox)
   - В разделе Local Storage найдите ваш домен
   - Удалите ключ `geolog_report_sections`
   - Или выполните в консоли: `localStorage.removeItem('geolog_report_sections')`

2. **Перезагрузите страницу** (F5)

3. **Откройте окно "Пояснительная записка":**
   - Кликните на "ПОЯСНИТЕЛЬНАЯ ЗАПИСКА" в навигаторе
   - Или: Меню → ОТЧЁТЫ DOCX → Пояснительная записка

4. **Проверьте консоль:**
   - Должны появиться сообщения:
     ```
     [ReportWindow] Инициализация новых разделов
     [ReportWindow] Готовые разделы по умолчанию: ['report-14', 'report-16']
     ```

5. **Проверьте индикаторы готовности:**
   - Раздел 14 ("Сведения о контроле качества и приемке работ") — зелёная галочка ✓
   - Раздел 16 ("Список использованной литературы") — зелёная галочка ✓
   - Все остальные разделы — красные крестики ✗

6. **Проверьте кнопки:**
   - У разделов 14 и 16 — зелёные кнопки "✓ Готово"
   - У остальных разделов — красные кнопки "✗ Не готово"

### Тест 2: Загрузка из localStorage (миграция)

1. **Создайте старые данные в localStorage:**
   - Выполните в консоли браузера:
     ```javascript
     const oldData = [
       { id: 'report-1', text: 'Текст 1', tableRows: [], isEdited: false, isSaved: true },
       { id: 'report-14', text: 'Текст 14', tableRows: [], isEdited: false, isSaved: true },
       { id: 'report-16', text: 'Текст 16', tableRows: [], isEdited: false, isSaved: true }
       // ... добавьте остальные разделы
     ];
     localStorage.setItem('geolog_report_sections', JSON.stringify(oldData));
     ```

2. **Перезагрузите страницу** (F5)

3. **Откройте окно "Пояснительная записка"**

4. **Проверьте консоль:**
   - Должны появиться сообщения о миграции:
     ```
     [ReportWindow] Загружено из localStorage: 3 разделов
     [ReportWindow] Миграция раздела report-1: isReady = false
     [ReportWindow] Миграция раздела report-14: isReady = true
     [ReportWindow] Миграция раздела report-16: isReady = true
     [ReportWindow] Готовые разделы: ['report-14', 'report-16']
     ```

5. **Проверьте индикаторы готовности:**
   - Раздел 14 — зелёная галочка ✓
   - Раздел 16 — зелёная галочка ✓
   - Раздел 1 — красный крестик ✗

### Тест 3: Переключение готовности

1. **Откройте окно "Пояснительная записка"**

2. **Нажмите кнопку "✗ Не готово" у раздела 1:**
   - Раздел становится готовым (зелёная галочка ✓)
   - Кнопка становится зелёной "✓ Готово"
   - В консоли: `[ReportWindow] Раздел report-1 отмечен как готов`

3. **Нажмите кнопку "✓ Готово" у раздела 14:**
   - Раздел становится неготовым (красный крестик ✗)
   - Кнопка становится красной "✗ Не готово"
   - В консоли: `[ReportWindow] Раздел report-14 отмечен как не готов`

4. **Перезагрузите страницу** (F5)

5. **Проверьте, что состояние сохранено:**
   - Раздел 1 — готов (✓)
   - Раздел 14 — не готов (✗)
