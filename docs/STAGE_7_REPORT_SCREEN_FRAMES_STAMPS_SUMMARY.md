  - Правая часть (60%): шифр, "Лист X", "Листов Y"
  - Шрифт: 8pt Times New Roman

- Большой штамп (185×55 мм):

  - Шифр проекта
  - Роли и даты (Разработал, Проверил, Н.контр., Утвердил)
  - Стадия, "Лист 1", "Листов Y"
  - Шрифт: 8pt Times New Roman
  - Границы: 0.3mm solid #000

**Файл:** `src/components/SheetStamp.tsx` (100 строк)

### 2. Создан компонент PageSheet.tsx

**Назначение:** Отображение листа формата A4/A3 с ГОСТ-рамкой и штампом

**Реализовано:**
- Поддержка форматов:
  - A4 portrait: 210×297 мм
  - A4 landscape: 297×210 мм
  - A3 portrait: 297×420 мм
  - A3 landscape: 420×297 мм

- ГОСТ-рамка:
  - Position: absolute
  - Отступы: left 20mm, right 5mm, top 5mm, bottom 5mm
  - Border: 0.5mm solid #000

- Масштабирование:
  - CSS transform: scale(k)
  - k = ширина контейнера / ширина листа в px
  - transform-origin: top left
  - ResizeObserver для отслеживания изменения размера
  - Обновление при resize окна

- Контент раздела:
  - Padding: top 10mm, bottom 20mm, left 25mm, right 10mm
  - Текст ВНУТРИ рамки с отступами
  - Шрифт: Times New Roman, 12pt, line-height 1.5

- Штамп:
  - Отображается поверх контента
  - Расположение: внизу внутри рамки
  - Тип зависит от pageSettings.stamp ('big', 'small', 'none')

**Файл:** `src/components/PageSheet.tsx` (120 строк)

### 3. Интеграция в ReportWindow.tsx

**Изменения:**
- Импортирован компонент PageSheet
- Заменён текущий div листа A4 на компонент PageSheet
- Переданы пропсы:
  - pageSettings: настройки листа для раздела
  - stampSettings: реквизиты штампа
  - pageNumber: порядковый номер раздела (1-based)
  - totalPages: общее количество разделов (49)

- Формат, ориентация, штамп, реквизиты обновляются мгновенно

**Файл:** `src/components/ReportWindow.tsx` (изменено ~10 строк)

## Технические детали

### Масштабирование

```typescript
const updateScale = () => {
  if (!containerRef.current) return;
  
  const containerWidth = containerRef.current.offsetWidth;
  const newScale = containerWidth / sheetWidth;
  setScale(newScale);
};

useEffect(() => {
  updateScale();
  window.addEventListener('resize', updateScale);
  
  const resizeObserver = new ResizeObserver(updateScale);
  if (containerRef.current) {
    resizeObserver.observe(containerRef.current);
  }
  
  return () => {
    window.removeEventListener('resize', updateScale);
    resizeObserver.disconnect();
  };
}, [sheetWidth, pageSettings.format, pageSettings.orientation]);
```

**Преимущества:**
- Плавное масштабирование при изменении размера окна
- Сохранение пропорций листа
- Нет горизонтального скролла
- Корректная работа с A3 и landscape ориентацией

### Размеры рамки

```typescript
const frameWidth = sheetWidth - FRAME_MARGINS.left - FRAME_MARGINS.right;
const frameHeight = sheetHeight - FRAME_MARGINS.top - FRAME_MARGINS.bottom;
```

**Константы:**
```typescript
const FRAME_MARGINS = {
  left: 20,   // мм
  right: 5,   // мм
  top: 5,     // мм
  bottom: 5   // мм
};
```

**Результат:**
- A4 portrait: рамка 185×287 мм
- A4 landscape: рамка 287×185 мм
- A3 portrait: рамка 287×410 мм
- A3 landscape: рамка 410×287 мм

### Нумерация страниц

```typescript
pageNumber={REPORT_SECTIONS.findIndex(s => s.id === section.id) + 1}
totalPages={REPORT_SECTIONS.length}
```

**Логика:**
- X = порядковый номер раздела в REPORT_SECTIONS (1-based)
- Y = REPORT_SECTIONS.length (49 разделов)
- В DOCX нумерация остаётся полями Word — не меняется
