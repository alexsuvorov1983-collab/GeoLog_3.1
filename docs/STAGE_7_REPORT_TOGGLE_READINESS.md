# Этап 7: Пояснительная записка - Переключатель готовности разделов

## Дата
2026-01-29

## Описание изменения
Изменена кнопка "Готово" на переключатель "Готово/Не готово" для всех разделов и приложений в модуле "Пояснительная записка".

## Что изменилось

### Старая логика
- Кнопка "Готово" отображалась только для неготовых разделов
- После нажатия кнопка скрывалась
- Невозможно было отменить готовность раздела

### Новая логика
- Кнопка отображается для всех разделов всегда
- Текст и цвет кнопки меняются в зависимости от состояния:
  - **Не готов**: зелёная кнопка "✓ Готово"
  - **Готов**: красная кнопка "✗ Не готово"
- При нажатии состояние переключается
- Индикатор (галочка) в навигации и заголовке меняется автоматически

## Визуальное оформление

### Кнопка "Готово" (раздел не готов)
- Цвет: зелёный (`bg-green-500`)
- Hover: более тёмный зелёный (`hover:bg-green-600`)
- Текст: "✓ Готово"
- Tooltip: "Отметить раздел как готовый"

### Кнопка "Не готово" (раздел готов)
- Цвет: красный (`bg-red-500`)
- Hover: более тёмный красный (`hover:bg-red-600`)
- Текст: "✗ Не готово"
- Tooltip: "Отметить раздел как не готовый"

### Индикаторы готовности
- **Зелёная галочка (✓)** — раздел готов
- **Красный крестик (✗)** — раздел не готов

## Порядок кнопок в разделе

```
[✎ Редактировать] [↺ Автогенерация] [✓ Готово / ✗ Не готово]
```

Кнопка переключателя всегда видна и меняет своё состояние при нажатии.

## Реализация

### Функция переключения готовности

```typescript
const toggleSectionReady = (sectionId: string) => {
  setSections(prev => prev.map(s => 
    s.id === sectionId 
      ? { ...s, isReady: !s.isReady }
      : s
  ));
  const section = sections.find(s => s.id === sectionId);
  const newStatus = section?.isReady ? 'не готов' : 'готов';
  Journal.logEvent('info', `Раздел ${sectionId} отмечен как ${newStatus}`, 'report.section_toggle');
};
```

### Кнопка переключателя

```tsx
<button
  onClick={() => toggleSectionReady(section.id)}
  className={`px-3 py-1 text-white rounded text-sm font-semibold ${
    isReady 
      ? 'bg-red-500 hover:bg-red-600' 
      : 'bg-green-500 hover:bg-green-600'
  }`}
  title={isReady ? 'Отметить раздел как не готовый' : 'Отметить раздел как готовый'}
>
  {isReady ? '✗ Не готово' : '✓ Готово'}
</button>
```

## Примеры использования

### Пример 1: Отметка раздела как готового
1. Раздел 1 "Введение" отмечен красным крестиком (✗)
2. Кнопка зелёная "✓ Готово"
3. Нажать кнопку "✓ Готово"
4. Раздел отмечается зелёной галочкой (✓)
5. Кнопка становится красной "✗ Не готово"

### Пример 2: Отмена готовности раздела
1. Раздел 14 "Сведения о контроле качества" отмечен зелёной галочкой (✓)
2. Кнопка красная "✗ Не готово"
3. Нажать кнопку "✗ Не готово"
4. Раздел отмечается красным крестиком (✗)
5. Кнопка становится зелёной "✓ Готово"

### Пример 3: Быстрое переключение
1. Пользователь может многократно нажимать кнопку
2. Состояние переключается каждый раз
3. Индикаторы обновляются мгновенно
4. Запись в журнал происходит при каждом переключении

## Сохранение состояния

- Состояние готовности сохраняется в `localStorage`
- При перезагрузке страницы состояние восстанавливается
- Каждое переключение записывается в журнал событий
